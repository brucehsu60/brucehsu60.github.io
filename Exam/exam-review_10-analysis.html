108.全國模考 (　　) 4. 若函數 $f(x) = 2 \sin \left( x + \d\frac{\pi}{6} \right) - 2 \cos x + 5$，則函數 $f(x)$ 的最大值為何？
(1) 7
(2) 5
(3) 3
(4) 1
(5) 0
🩺 手寫草稿診斷與盲點剖析
・草稿跡象：草稿中在題目下方畫了一個波浪圖，把減號圈起來，完全沒有用和角公式展開 $\sin\left(x + \d\frac{\pi}{6}\right)$，就直接刪去 (3)(4)(5) 並選了 (1) $7$。
・潛在危機：很可能是直覺認為「前面係數是 $2$，所以最大值就是 $2 + 5 = 7$」。這題剛好因為展開後 $2\sin\left(x+\d\frac{\pi}{6}\right) - 2\cos x = \sqrt{3}\sin x - \cos x$，疊合後振幅 $\sqrt{(\sqrt{3})^2 + (-1)^2} = 2$ 沒變，所以湊巧算對！
・反例警示：如果題目把減號改成加號：$f(x) = 2\sin\left(x + \d\frac{\pi}{6}\right) + 2\cos x + 5 = \sqrt{3}\sin x + 3\cos x + 5$，振幅就會變成 $\sqrt{(\sqrt{3})^2 + 3^2} = \sqrt{12} = 2\sqrt{3}$，最大值就是 $2\sqrt{3} + 5$ 而不是 $7$ 了！
📘 訂正標準步驟（和角展開 $\to$ 同類項合併 $\to$ 正餘弦疊合）
遇到不同相位的 $\sin\left(x + \d\frac{\pi}{6}\right)$ 與 $\cos x$ 相加減，務必先用正弦和角公式展開： $$\begin{aligned} f(x) &= 2\left(\sin x \cos\d\frac{\pi}{6} + \cos x \sin\d\frac{\pi}{6}\right) - 2\cos x + 5 \\ &= 2\left(\d\frac{\sqrt{3}}{2}\sin x + \d\frac{1}{2}\cos x\right) - 2\cos x + 5 \\ &= \sqrt{3}\sin x - \cos x + 5 \\ &= \sqrt{(\sqrt{3})^2 + (-1)^2}\left(\d\frac{\sqrt{3}}{2}\sin x - \d\frac{1}{2}\cos x\right) + 5 = 2\sin\left(x - \d\frac{\pi}{6}\right) + 5 \end{aligned}$$ 因為 $-1 \le \sin\left(x - \d\frac{\pi}{6}\right) \le 1$，所以 $f(x)$ 的最大值為 $2 \times 1 + 5 = 7$。
最終答案：(1)

・盲點診斷：忘了 $\sin 2\theta$ 可以直接拆成二倍角公式判別正負號，也不確定 $2\theta$ 落在哪個象限。
⚡ 學霸秒殺補強（1 秒判別 $\sin 2\theta$ 正負號）
已知 $\theta$ 為第二象限角，代表 $\sin\theta > 0$ 且 $\cos\theta < 0$。
看到選項 (4) 的 $\sin 2\theta$，根本不用算角度範圍，直接套用二倍角公式： $$\sin 2\theta = 2\sin\theta\cos\theta = 2 \times (+) \times (-) < 0$$ 正數乘以負數必為負數！1 秒鐘確定選項 (4) 恆成立！
📘 正規詳解（廣義角範圍法）
設 $90^\circ + 360^\circ \times n < \theta < 180^\circ + 360^\circ \times n$（$n \in \mathbb{Z}$）：
・同除以 $2$：$45^\circ + 180^\circ \times n < \d\frac{\theta}{2} < 90^\circ + 180^\circ \times n$，故 $\d\frac{\theta}{2}$ 為第一或第三象限角，$\tan\d\frac{\theta}{2} > 0$ 恆成立，(1)(2) 錯、(3) 對。
・同乘以 $2$：$180^\circ + 720^\circ \times n < 2\theta < 360^\circ + 720^\circ \times n$，故 $2\theta$ 落在 $x$ 軸下方（第三、四象限或負 $y$ 軸），因此 $\sin 2\theta < 0$ 恆成立；而當 $2\theta$ 在第四象限時 $\cos 2\theta > 0$，故 (4) 對、(5) 錯。
最終答案：(3)(4)

(　　) 6. 下列哪些函數的週期為 $\pi$？

📘 訂正重點（兩種方法秒懂為什麼 $y = \cos^2 x$ 週期是 $\pi$）
  • 方法一（代數降次公式——必背）：
    由二倍角公式 $\cos 2x = 2\cos^2 x - 1$ 移項可得： $$y = \cos^2 x = \d\frac{1 + \cos 2x}{2} = \d\frac{1}{2}\cos 2x + \d\frac{1}{2}$$ 因為角度變為 $2x$，所以週期為 $\d\frac{2\pi}{2} = \pi$！
  • 方法二（圖形翻折直覺——與第 5 選項相通）：
    既然已經知道選項 (5) 加絕對值 $|\sin x + \cos x|$ 會把 $x$ 軸下方的負半波翻折上來，使週期減半為 $\pi$；那麼平方 $y = \cos^2 x = |\cos x|^2$ 同樣也是把負半波全部變成正的拱形，週期當然也會減半為 $\pi$！
最終答案：(1)(3)(5)

    ・二次方求週期：$y = \cos^2 x = \d\frac{1 + \cos 2x}{2}$、$y = \sin^2 x = \d\frac{1 - \cos 2x}{2}$，平方或加絕對值後，正弦與餘弦的週期都會減半為 $\pi$！
  3. 【處方 3：針對第 4、12 題】落實正餘弦疊合標準動作：
    遇到 $2\sin\left(x + \d\frac{\pi}{6}\right) \pm 2\cos x$ 或 $\sin\alpha - \cos\alpha$，務必先展開合併成 $a\sin x + b\cos x$，再提出振幅 $\sqrt{a^2 + b^2}$，切勿直接拿原式前面的係數當作最大值！
  4. 【處方 4：針對第 8 題與混合題】斜率正負號檢核與手寫題先寫結論：
    ・當直線向右下傾斜（$m_2 < 0$）且銳夾角為 $\theta_2$ 時，每個選項都要把 $\tan\theta_2 = -m_2$ 代入檢驗。
    ・混合題手寫證明務必第一行先寫出明確結論（如：「一樣長」），善用圖形對稱性省去繁瑣的斜率運算。
