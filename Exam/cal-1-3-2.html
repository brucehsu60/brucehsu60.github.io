🎯 高斯方程式五大核心解法總整理

對於任意實數 $x$，$[x] \leq x < [x]+1$
利用此性質求滿足 $[x] = 2x - 1$ 的所有解。

🛡️ 方法一：正規代數參數法（最穩健，手寫題必備）

  • 參數化： 令 $[x] = k$（其中 $k \in \mathbb{Z}$）。
  • 代換方程式： 將 $[x] = k$ 代入原方程式，得 $k = 2x - 1 \implies x = \d\frac{k + 1}{2}$。
  • 代入不等式限制： 題目已給定性質 $[x] \leq x < [x]+1$，將 $k$ 與 $x$ 同時代入不等式： $$k \leq \d\frac{k + 1}{2} < k + 1$$
  • 解不等式求整數 $k$： 同乘 2 得 $2k \leq k + 1 < 2k + 2$。
    拆分左右求解後合併範圍，得到 $-1 < k \leq 1$。
    因 $k$ 為整數，故 $k = 0$ 或 $k = 1$。
  • 收尾求 $x$： 代回 $x = \frac{k+1}{2}$，得到解為 $x = 0.5$ 或 $x = 1$。

⚡ 方法二：小數部分與整數特性分析（學霸秒殺法）

  • 鎖定倍數特性： 方程式 $[x] = 2x - 1$ 中，左邊是整數，所以右邊的 $2x - 1$ 也必須是整數。推論出 $2x$ 是整數，即 $x$ 必定是 $0.5$ 的整數倍。
  • 引入小數部分 $\{x\}$： 實數可拆為 $x = [x] + \{x\}$，移項得 $[x] = x - \{x\}$。
  • 代入原式： 將其代入原式： $x - \{x\} = 2x - 1 \implies x = 1 - \{x\}$。
  • 利用小數範圍精準打擊： 因為小數部分 $0 \leq \{x\} < 1$，所以 $1 - \{x\}$ 的範圍落在： $$0 < 1 - \{x\} \leq 1$$ 這代表 解答 $x$ 必須落在 $(0, 1]$ 區間內。結合 Step 1 得知，在此區間內 $0.5$ 的倍數只有 $0.5$ 與 $1$ 兩個可能。

📉 方法三：函數圖形交點法（幾何直觀，最強驗算工具）

  • 拆解方程式： 將原式視為尋找 $y_1 = [x]$ 與 $y_2 = 2x - 1$ 兩個函數的交點。
  • 作圖分析：
    • $y_1$ 是階梯函數（每經過整數跳躍一次）。
    • $y_2$ 是斜率為 2 的直線。
  • 尋找交點： 在 $0 \leq x < 1$ 時階梯高度為 $0$；直線 $2x-1 = 0 \implies x = 0.5$。得到交點 $(0.5, 0)$。
    在 $x = 1$ 時階梯躍升為 $1$；直線 $2(1)-1 = 1$。得到交點 $(1, 1)$。
  • 極限判斷直線太陡，不會再有其他交點。

🔮 方法四：直接不等式夾擠法（免設代號，最快求範圍）

  • 直接替換不等式核心： 題目給定 $[x] \leq x < [x] + 1$。
    我們直接將其中的 $[x]$ 全部用 $(2x - 1)$ 替換掉： $$2x - 1 \leq x < (2x - 1) + 1 \implies 2x - 1 \leq x < 2x$$
  • 解開絕對領域： 將不等式拆成兩半來解：
    左半邊：$2x - 1 \leq x \implies x \leq 1$
    右半邊：$x < 2x \implies 0 < x$
    兩者交集立刻得到： $$0 < x \leq 1$$
  • 整數收斂： 因 $[x]=2x-1$ 為整數，故 $2x$ 必須為整數。將剛求出的範圍同乘 2 得 $0 < 2x \leq 2$。裡面的整數僅有 $1$ 與 $2$，推得 $x = 0.5$ 或 $1$。

🧩 方法五：整數奇偶分類法（邏輯狂人專用）

  • 假設分數型態： 由原式知 $2x$ 是整數，令 $x = \d\frac{n}{2}$（其中 $n \in \mathbb{Z}$）。
  • 建立整數方程式： 代入原式得： $\left[\d\frac{n}{2}\right] = n - 1$。
  • 針對 $n$ 進行奇偶探討：
    【偶數】 令 $n = 2m$： $\left[\d\frac{2m}{2}\right] = 2m - 1 \implies m = 2m - 1 \implies m = 1$。此時 $n=2$，$x = \mathbf{1}$。
    【奇數】 令 $n = 2m + 1$： $\left[\d\frac{2m+1}{2}\right] = (2m+1) - 1 \implies [m + 0.5] = 2m$。
    整數加 0.5 取高斯會捨去尾數，故 $m = 2m \implies m = 0$。此時 $n=1$，$x = \mathbf{0.5}$。
🎯 最終答案： $x = \d\frac{1}{2}$ 或 $x = 1$
