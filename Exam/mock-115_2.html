1. 在 $1$、$2$、$3$、$4$、$5$ 這五個數字中，任選三個相異數字排成三位數，其中為偶數的三位數共有 $4\times 3\times 2 = 24$ 個，試問這 $24$ 個偶數的中位數為何？
(1) $331$(2) $332$(3) $333$(4) $334$(5) $335$
📘 【正規詳解（官方詳解法）】由小到大分類定位第 12、13 項
將 $24$ 個偶數從小排到大依序為 $x_1, x_2, \dots, x_{24}$，因為 $\d\frac{24}{2} = 12$，故中位數為 $\d\frac{x_{12} + x_{13}}{2}$：
  • 形如 $1\square 2$ 或 $1\square 4$：共 $3 \times 2 = 6$ 個。
  • 形如 $2\square 4$：共 $3 \times 1 = 3$ 個。
  • 百位為 $3$ 的前兩個：$312, 314$ 共 $2$ 個（以上累計 $6 + 3 + 2 = 11$ 個偶數）。
接著第 $12$ 個與第 $13$ 個偶數分別為 $x_{12} = 324$、$x_{13} = 342$，故中位數為 $\d\frac{324 + 342}{2} = 333$。
⚡ 【學霸最佳秒殺法】數位互補對稱法（$d \leftrightarrow 6-d$）
將每個數字 $d \in \{1,2,3,4,5\}$ 對應為 $6-d$。因為偶數個位 $2 \leftrightarrow 4$ 仍為偶數，所以若 $N$ 為此集合中的偶數，則 $666 - N$ 必也在此集合中！由大小對稱性，$x_{12} + x_{13} = 666$，中位數 $= \d\frac{666}{2} = 333$。
最終答案：(3)
2. 設 $a$ 為實數，則坐標平面上點 $P(3, 2)$ 到直線 $L: y + a^2 = -\d\frac{1}{2}x - 2a$ 的距離之最小值為何？
(1) $\d\frac{2}{\sqrt{5}}$(2) $\d\frac{7}{\sqrt{5}}$(3) $\d\frac{9}{2\sqrt{5}}$(4) $\sqrt{5}$(5) $\d\frac{\sqrt{5}}{2}$
📘 【正規詳解（官方詳解法）】點到直線距離公式＋二次函數配方法
將直線 $L$ 整理為一般式：$2y + 2a^2 = -x - 4a \implies L: x + 2y + 2a^2 + 4a = 0$。
由點到直線距離公式： $$d(P, L) = \d\frac{|3 + 2(2) + 2a^2 + 4a|}{\sqrt{1^2 + 2^2}} = \d\frac{|2a^2 + 4a + 7|}{\sqrt{5}} = \d\frac{2(a + 1)^2 + 5}{\sqrt{5}}$$ 當 $a = -1$ 時，$d(P, L)$ 有最小值 $\d\frac{5}{\sqrt{5}} = \sqrt{5}$。
最終答案：(4)
3. 已知數列 $\langle a_n \rangle$ 是一個首項為 $10$，公比為 $4$，共有 $20$ 項的等比數列，試問數列 $\langle a_n \rangle$ 中，共有幾項為 $10$ 位數？
(1) $0$ 項(2) $1$ 項(3) $2$ 項(4) $3$ 項(5) $4$ 項
📘 【正規詳解（官方詳解法）】科學記號與常用對數判定位數
一般項 $a_n = 10 \times 4^{n-1}$。若 $a_n$ 為 $10$ 位數，則 $10^9 \le 10 \times 4^{n-1} < 10^{10} \implies 10^8 \le 4^{n-1} < 10^9$。
因為 $\log 2 \approx 0.3010 \implies 4 \approx 10^{0.602}$，代入得： $$10^8 \le 10^{0.602(n-1)} < 10^9 \implies 8 \le 0.602(n - 1) < 9 \implies \d\frac{8}{0.602} \le n - 1 < \d\frac{9}{0.602}$$ 計算得 $13.28\cdots \le n - 1 < 14.95\cdots \implies 14.28\cdots \le n < 15.95\cdots$，故僅有 $a_{15}$ 共 $1$ 項為 $10$ 位數。
最終答案：(2)

5. 一袋中有五顆球，球上分別印有號碼 $1, 3, 4, 5, 7$。現從袋中隨機抽取一顆球，取後不放回，共抽取三次，假設每次抽球時，袋中每顆球被抽取的機會相等。已知三次抽取出球上的號碼依序為 $a, b, c$，則 $ab + c$ 的期望值為何？
(1) $16$(2) $18$(3) $19$(4) $20$(5) $24$
📘 【正規詳解（官方詳解法）】分別求 $ab$ 與 $c$ 的期望值
  1. 先求 $ab$ 的期望值 $E_1$：從 $5$ 顆球取 $2$ 顆相異球排列有 $5 \times 4 = 20$ 種，每組兩數乘積出現 $2!$ 次： $$E_1 = \d\frac{2!}{5 \times 4}(1\times 3 + 1\times 4 + 1\times 5 + 1\times 7 + 3\times 4 + 3\times 5 + 3\times 7 + 4\times 5 + 4\times 7 + 5\times 7) = \d\frac{2}{20} \times 150 = 15$$
  2. 再求 $c$ 的期望值 $E_2$：每顆球在第三次被抽出的機率均為 $\d\frac{1}{5}$，故 $E_2 = \d\frac{1 + 3 + 4 + 5 + 7}{5} = 4$。
所求期望值為 $E_1 + E_2 = 15 + 4 = 19$。
⚡ 【學霸最佳代數速算法】免列舉！利用乘法公式求 $\sum_{i \ne j} x_i x_j$
不必逐一列出 $10$ 組乘積！直接由 $\d\sum_{i \ne j} x_i x_j = \left(\sum x_i\right)^2 - \sum x_i^2 = 20^2 - (1 + 9 + 16 + 25 + 49) = 400 - 100 = 300$，除以 $P^5_2 = 20$ 立得 $E(ab) = \d\frac{300}{20} = 15$，加上 $E(c) = 4$ 得 $19$。
最終答案：(3)

8. 設首項係數為 $1$ 的二次實係數多項式 $f(x)$ 滿足 $xf(x)$ 除以 $x^2 + x + 1$ 的商式為 $q(x)$，餘式為 $x - 5$，試選出正確的選項。
(1) $q(x)$ 必定為一次多項式 (2) $q(0) = 5$ (3) $f(-1) + q(-1) = 6$ (4) 不等式 $f(x) > 0$ 的解為任意實數 (5) $x^2f(x)$ 除以 $x^2 + x + 1$ 的餘式為 $-6x - 1$
📘 【最佳詳解（官方解法二）】除法原理結合代值秒殺
因為 $xf(x)$ 為首項係數 $1$ 的三次式，除以 $x^2 + x + 1$ 的商式 $q(x)$ 必為首項係數 $1$ 的一次式，令 $q(x) = x + a$。
由除法原理：$xf(x) = (x^2 + x + 1)(x + a) + (x - 5)$。
  • (1) 正確：$q(x) = x + a$ 為一次多項式。
  • (2) 正確：代入 $x = 0$ 得 $0 = 1 \cdot a - 5 \implies a = 5$，故 $q(x) = x + 5 \implies q(0) = 5$。
  • (3) 正確：將 $q(x) = x + 5$ 代回展開：$xf(x) = (x^2+x+1)(x+5)+x-5 = x^3 + 6x^2 + 7x \implies f(x) = x^2 + 6x + 7$。
    故 $f(-1) + q(-1) = (1 - 6 + 7) + (-1 + 5) = 6$（或直接將原式代 $x = -1$ 得 $-f(-1) = q(-1) - 6$）。
  • (4) 錯誤：$f(x) = x^2 + 6x + 7$ 的判別式 $D = 6^2 - 4(1)(7) = 8 > 0$，與 $x$ 軸有兩交點，故 $f(x) > 0$ 的解不為任意實數。
  • (5) 正確：$x^2f(x) = x(x^2+x+1)(x+5) + (x^2 - 5x) = (x^2+x+1)(x^2+5x+1) + (-6x - 1)$，故餘式為 $-6x - 1$。
最終答案：(1)(2)(3)(5)

已知 $\vec{e}_1 \cdot \vec{e}_2 = 1 \times 1 \times \cos 60^\circ = \d\frac{1}{2}$，且 $\overrightarrow{OP_1} = -\vec{e}_1 + 3\vec{e}_2$，$\overrightarrow{OP_2} = 3\vec{e}_1 - \vec{e}_2$：

📘 【最佳詳解】餘弦定理＋四點共圓性質（圓內接四邊形）
  • (1) 錯誤：設 $\overline{AB} = x$，$\angle ADB = \angle ACB = \theta$。在 $\triangle ADB$ 與 $\triangle ACB$ 中由餘弦定理： $$\cos\theta = \d\frac{7^2 + 7^2 - x^2}{2\times 7\times 7} = \d\frac{8^2 + 5^2 - x^2}{2\times 8\times 5} \implies \d\frac{98 - x^2}{98} = \d\frac{89 - x^2}{80} \implies x^2 = 49 \implies \overline{AB} = 7\text{ 公尺}$$ 且因此 $\triangle ABD$ 三邊皆為 $7$，為正三角形，$\theta = 60^\circ$！
  • (2) 正確：因為 $\angle ADB = \angle ACB = 60^\circ$，故 $A, B, C, D$ 四點共圓。在 $\triangle ACD$ 中，$\angle ACD = \angle ABD = 60^\circ$（同弧圓周角），由餘弦定理： $$7^2 = 8^2 + \overline{CD}^2 - 2\times 8\times \overline{CD}\cos 60^\circ \implies \overline{CD}^2 - 8\overline{CD} + 15 = 0 \implies \overline{CD} = 3 \text{ 或 } 5\text{（5 不合，因 } C \ne D\text{）}$$ （學霸秒殺另解：直接由托勒密定理 $7\cdot\overline{CD} + 5\cdot 7 = 8\cdot 7 \implies \overline{CD} = 3$！）
  • (3) 正確：圓內接四邊形對角互補，$\angle BCD = 180^\circ - \angle BAD = 180^\circ - 60^\circ = 120^\circ$，故 $\cos\angle BCD = -\d\frac{1}{2}$。
  • (4) 正確：四邊形面積 $= \triangle ABD + \triangle BCD = \d\frac{\sqrt{3}}{4}\times 7^2 + \d\frac{1}{2}\times 5\times 3\sin 120^\circ = \d\frac{49\sqrt{3} + 15\sqrt{3}}{4} = 16\sqrt{3}$。
  • (5) 錯誤：最小外接圓即為正 $\triangle ABD$ 的外接圓，半徑 $R = \d\frac{7}{2\sin 60^\circ} = \d\frac{7\sqrt{3}}{3}$ 公尺（$\d\frac{14\sqrt{3}}{3}$ 為直徑）。
⚡ 【官方詳解另解】差角公式求 $\overline{CD}$
在 $\triangle ABC$ 中，$\cos\angle CAB = \d\frac{8^2+7^2-5^2}{2\times 8\times 7} = \d\frac{11}{14} \implies \sin\angle CAB = \d\frac{5\sqrt{3}}{14}$。

13. 設 $a, b, c$ 為實數且 $a \ne 0$，已知三次函數 $f(x) = -x^3 + ax^2 + bx + c$ 圖形的對稱中心為 $(-2, 0)$，且二次函數 $g(x) = ax^2 + bx + c$ 的對稱軸方程式是 $x = \d\frac{1}{3}$，則 $4a + b + c =$  13 。
📘 【正規詳解】三次函數對稱中心與二次函數對稱軸公式
  1. 三次函數 $f(x) = -x^3 + ax^2 + bx + c$ 對稱中心的 $x$ 坐標為 $-\d\frac{a}{3(-1)} = -2 \implies a = -6$。
  2. 二次函數 $g(x) = ax^2 + bx + c$ 的對稱軸為 $x = -\d\frac{b}{2a} = \d\frac{1}{3} \implies b = -\d\frac{2}{3}a = -\d\frac{2}{3}(-6) = 4$。
  3. 對稱中心 $(-2, 0)$ 在 $y = f(x)$ 圖形上，代入得： $$f(-2) = -(-2)^3 + a(-2)^2 + b(-2) + c = 8 + 4a - 2b + c = 0 \implies c = -8 - 4(-6) + 2(4) = 24$$
故 $4a + b + c = 4(-6) + 4 + 24 = 4$。（秒殺觀察：由 $4a - 2b + c = -8$ 直接兩邊加 $3b$ 得 $4a + b + c = -8 + 3(4) = 4$，免算 $a, c$！）

📘 【正規詳解】同底三角形面積比＝高之比＝對角線分段比

16. 若正數 $a, b$ 滿足 $2 + \log_2 a = 4 + \d\frac{1}{2}\log_2 b = \d\frac{1}{3}\log_2(a + b)$，則 $\d\frac{1}{a} + \d\frac{1}{b}$ 的值為  16-116-216-316-4 。
📘 【學霸最佳秒殺詳解】化為同底對數後免求 $a, b$ 直接消去！
利用對數律將三式合併為以 $2$ 為底的單一對數： $$\log_2(4a) = \log_2(16\sqrt{b}) = \log_2(a + b)^{\frac{1}{3}} \implies 4a = 16\sqrt{b} = (a + b)^{\frac{1}{3}}$$ 由此直接寫出 $a$ 與 $b$ 關於 $(a+b)$ 的表示式： $$a = \d\frac{1}{4}(a + b)^{\frac{1}{3}},\qquad b = \d\frac{1}{256}(a + b)^{\frac{2}{3}}$$ 兩式相乘，指數 $\d\frac{1}{3} + \d\frac{2}{3} = 1$ 剛好湊成 $(a + b)$： $$ab = \d\frac{1}{4}\times\d\frac{1}{256}(a + b)^{\frac{1}{3} + \frac{2}{3}} = \d\frac{a + b}{1024} \implies \d\frac{1}{a} + \d\frac{1}{b} = \d\frac{a + b}{ab} = 1024$$

17. 投擲三個公正骰子一次，若以三個朝上面的點數作為三角形的三邊長，則可構成等腰三角形（含正三角形）的機率為 $\d\frac{\text{(17-1)(17-2)}}{\text{(17-3)(17-4)}}$。（化為最簡分數）
📘 【正規詳解】按腰長 $a$ 分類討論三角不等式 $2a > b$
樣本空間總數為 $6^3 = 216$。設等腰三角形三邊為 $(a, a, b)$，需滿足兩腰和大於底邊 $a + a > b \iff b < 2a$：
  1. 正三角形（$a = b$）：$(1,1,1) \sim (6,6,6)$，共 $6 \times 1 = 6$ 種。
  2. 非正三角形之等腰三角形（$a \ne b$ 且 $b < 2a$）：每組 $(a, a, b)$ 可排列出 $\d\frac{3!}{2!} = 3$ 種結果：
    • 腰 $a = 1$：$b < 2$ 且 $b \ne 1 \implies 0$ 組。
    • 腰 $a = 2$：$b \in \{1, 3\} \implies 2$ 組。
    • 腰 $a = 3$：$b \in \{1, 2, 4, 5\} \implies 4$ 組。

故所求機率為 $\d\frac{6 + 63}{216} = \d\frac{69}{216} = \d\frac{23}{72}$。

📘 【第 18 題 正規詳解】圓的切線方程式求交點 $R$
圓 $C: x^2 + (y - 3)^2 = 4$ 的圓心為 $M(0, 3)$，半徑 $r = 2$。
  1. 直線 $PQ$ 的方程式為鉛垂線 $x = -2$，恰與圓 $C$ 相切於 $(-2, 3)$。
  2. 過 $P(-2, 1)$ 的另一條切線為水平線 $L_{PR}: y = 1$（因為圓心 $M(0, 3)$ 到 $y = 1$ 的距離為 $3 - 1 = 2 = r$，切點為 $(0, 1)$）。
  3. 設過 $Q(-2, 7)$ 的另一條切線為 $L_{QR}: y - 7 = m(x + 2) \implies mx - y + (2m + 7) = 0$。
    由圓心 $M(0, 3)$ 到 $L_{QR}$ 的距離等於半徑 $2$： $$\d\frac{|0 - 3 + 2m + 7|}{\sqrt{m^2 + 1}} = 2 \implies |2m + 4| = 2\sqrt{m^2 + 1} \implies (m + 2)^2 = m^2 + 1 \implies m = -\d\frac{3}{4}$$ 故切線 $L_{QR}$ 方程式為 $y - 7 = -\d\frac{3}{4}(x + 2)$。
  4. 解 $L_{PR}$ 與 $L_{QR}$ 的交點 $R$：將 $y = 1$ 代入得 $1 - 7 = -\d\frac{3}{4}(x + 2) \implies x = 6$，故 $R$ 點坐標為 $(6, 1)$。
⚡ 【第 18 題 學霸幾何秒殺另解】二倍角公式與切線長定理
