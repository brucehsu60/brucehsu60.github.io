一、廣義角、同界角與象限正負判別 📍 對應本卷：第 5 題、第 11 題
處理廣義角（包含負角或大於 $360^\circ$ 的角）以及三角形內角關係時，必須掌握同界角一般式、四象限正負號（ASTC）與廣義角化簡（誘導公式）。
📘 核心公式與觀念詳解
1. 同界角一般式（以第二象限角為例）：
　若已知 $\theta$ 為第二象限角，必須寫為： $$90^\circ + 360^\circ \times n < \theta < 180^\circ + 360^\circ \times n \quad (\text{其中 } n \in \mathbb{Z})$$ 　・半角 $\d\frac{\theta}{2}$ 的範圍：同除以 $2$ 得 $45^\circ + 180^\circ \times n < \d\frac{\theta}{2} < 90^\circ + 180^\circ \times n$。當 $n$ 為偶數時在第一象限；當 $n$ 為奇數時在第三象限。
　・倍角 $2\theta$ 的範圍：同乘以 $2$ 得 $180^\circ + 720^\circ \times n < 2\theta < 360^\circ + 720^\circ \times n$，終邊落在第三象限、第四象限或負 $y$ 軸上。
2. 廣義角誘導公式（奇變偶不變，正負看象限）：
　・在 $\triangle ABC$ 中，因為 $A + B + C = 180^\circ$，所以： $$\sin C = \sin(180^\circ - (A + B)) = \sin(A + B) \quad , \quad \cos C = -\cos(A + B)$$ 　・常見平移化簡：$\sin(x + \pi) = -\sin x$，$\cos(x + \pi) = -\cos x$，$\sin\left(x + \d\frac{\pi}{2}\right) = \cos x$。
⚠️ 易錯盲點（考場第一高頻陷阱）
看到「$\theta$ 為第二象限角」，千萬不可只寫 $90^\circ < \theta < 180^\circ$ 就直接除以 $2$ 得到 $45^\circ < \d\frac{\theta}{2} < 90^\circ$！漏寫 $+360^\circ n$ 會直接遺漏第三象限（例如 $\theta = 460^\circ \implies \d\frac{\theta}{2} = 230^\circ$）。
⏱️ 學霸考場驗算（倍半角恆等式直接判號法）
不喜歡討論 $n$ 的奇偶性嗎？已知 $\theta \in \text{II}$（即 $\sin\theta > 0, \cos\theta < 0$），直接代恆等式：
・$\sin 2\theta = 2\sin\theta\cos\theta = 2(+)(-) < 0$（秒證恆負！）
・$\tan\d\frac{\theta}{2} = \d\frac{1 - \cos\theta}{\sin\theta} = \d\frac{1 - (-)}{+} > 0$（秒證恆正！）
核心記憶口訣：半角象限看奇偶（對頂象限 $\tan$ 同號）；三角形內角 $\sin(A+B) = \sin C$。
二、弧度（弳）與扇形的弧長、面積公式 📍 對應本卷：第 3 題、第 9 題、混合題第 2 小題
當圓心角以弧度（弳，radian）表示時，扇形的弧長與面積公式會變得極為簡潔，且扇環（兩同心扇形之差）可直接用「曲邊梯形」的概念快速求解。
📘 核心公式與觀念詳解
1. 角度與弳度換算：$\pi \text{（弳）} = 180^\circ$，$1 \text{（弳）} = \d\frac{180^\circ}{\pi} \approx 57.3^\circ$。
2. 扇形弧長公式：設圓半徑為 $r$，圓心角為 $\theta$（弳），則弧長為： $$s = r\theta$$ 3. 扇形面積公式： $$A = \d\frac{1}{2}r^2\theta = \d\frac{1}{2}rs$$ 4. 扇環（灰色區域）面積公式：大扇形減小扇形，並利用平方差公式因式分解： $$A_{\text{扇環}} = \d\frac{1}{2}r_1^2\theta - \d\frac{1}{2}r_2^2\theta = \d\frac{1}{2}\theta(r_1 - r_2)(r_1 + r_2)$$
⚡ 學霸另解（扇環面積＝梯形公式秒殺法）
把扇環想像成「上底為內弧 $s_2 = r_2\theta$、下底為外弧 $s_1 = r_1\theta$、高為 $\Delta r = r_1 - r_2$」的曲邊梯形：
$$A_{\text{扇環}} = \d\frac{s_1 + s_2}{2} \times (r_1 - r_2) = s_{\text{中線}} \times \text{高} = \left(\d\frac{r_1 + r_2}{2}\cdot\theta\right)(r_1 - r_2)$$ 已知面積與高 $(r_1 - r_2)$，一秒鐘就能算出正中央的平均半徑 $\d\frac{r_1 + r_2}{2}$！
核心記憶口訣：用公式前先確認 $\theta$ 是「弳」；求優弧長記得用 $(2\pi - \theta)$ 乘以半徑 $r$。
三、和差角、二倍角與平方降次公式 📍 對應本卷：第 1、4、5、6、8、10、11、12 題、混合題
和差角與倍半角公式貫穿整張考卷超過 $70\%$ 的題目，務必做到「正向展開」與「逆向合併」都能反射性寫出。
📘 核心公式與觀念詳解
1. 正弦與餘弦的和差角公式： $$\begin{aligned} \sin(\alpha + \beta) &= \sin\alpha\cos\beta + \cos\alpha\sin\beta \quad , \quad \sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta \\ \cos(\alpha + \beta) &= \cos\alpha\cos\beta - \sin\alpha\sin\beta \quad , \quad \cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta \end{aligned}$$ 2. 正切的和差角公式： $$\tan(\alpha + \beta) = \d\frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta} \quad , \quad \tan(\alpha - \beta) = \d\frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$ 3. 二倍角公式（三大變形）： $$\begin{aligned} \sin 2\theta &= 2\sin\theta\cos\theta \implies \sin\theta\cos\theta = \d\frac{1}{2}\sin 2\theta \\ \cos 2\theta &= \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta \\ \tan 2\theta &= \d\frac{2\tan\theta}{1 - \tan^2\theta} \end{aligned}$$ 4. 平方降次公式（將二次方降為一次方，求週期與積分必備）： $$\sin^2 x = \d\frac{1 - \cos 2x}{2} \quad , \quad \cos^2 x = \d\frac{1 + \cos 2x}{2}$$
💡 考場秒殺觀察：逆用公式的訊號
・看到 $\cos A\cos B + \sin A\sin B$ 結構（如第 1 題）：立刻逆向收攏為 $\cos(A - B)$！
・看到 $\sin x\cos x$ 相乘（如第 6 題）：立刻化為 $\d\frac{1}{2}\sin 2x$，角度變 $2x$，週期立刻減半為 $\pi$！
・看到角平分線給出半角 $\sin\theta$ 卻要求全角 $\cos 2\theta$（如第 10 題）：直接代 $\cos 2\theta = 1 - 2\sin^2\theta$，完全不必求 $\cos\theta$！
核心記憶口訣：$\sin$ 和角「辛口＋口辛」（同號）；$\cos$ 和角「口口－辛辛」（異號）。
四、直線的斜角、斜率與兩直線夾角公式 📍 對應本卷：第 8 題、混合題第 1 & 2 小題
坐標平面上直線的斜率 $m$ 就是其有向斜角的正切值。處理兩直線夾角問題時，結合斜率與正切差角公式即可無往不利。
📘 核心公式與觀念詳解
1. 有向斜角與銳夾角的轉換（第 8 題核心）：
　設水平線為 $L$，直線 $L_1, L_2$ 與 $L$ 的銳夾角分別為 $\theta_1, \theta_2 \in (0^\circ, 90^\circ)$：
　・若 $m_1 > 0$（向右上傾斜）：有向斜角為 $+\theta_1 \implies m_1 = \tan\theta_1$。
　・若 $m_2 < 0$（向右下傾斜）：有向斜角為 $-\theta_2 \implies m_2 = \tan(-\theta_2) = -\tan\theta_2 \implies \tan\theta_2 = -m_2$。
2. 兩直線垂直條件：若兩直線互相垂直（且皆不平行座標軸），則 $m_1 \times m_2 = -1$。
3. 兩直線夾角公式：設兩直線斜率分別為 $m_1, m_2$，其夾角為 $\theta$，則： $$\tan\theta = \pm\d\frac{m_1 - m_2}{1 + m_1 m_2}$$
⚠️ 易錯盲點：鈍角與正切值的正負關係
當兩個銳角相加 $\theta_1 + \theta_2 \in (0^\circ , 180^\circ)$ 時：
・若 $\tan(\theta_1 + \theta_2) > 0 \iff 0^\circ < \theta_1 + \theta_2 < 90^\circ$（銳角）；
・若 $\tan(\theta_1 + \theta_2) < 0 \iff 90^\circ < \theta_1 + \theta_2 < 180^\circ$（鈍角）。
在第 8 題中，當 $m_1 > 0, m_2 < 0$ 且 $m_1 m_2 < -1$ 時，$\tan(\theta_1 + \theta_2) = \d\frac{m_1 - m_2}{1 + m_1 m_2} = \d\frac{+}{-} < 0$，立刻推得 $\theta_1 + \theta_2 > 90^\circ$！
核心記憶口訣：題目給「銳夾角 $\theta$」且斜率 $m < 0$ 時，務必先寫 $\tan\theta = -m$！
五、正餘弦函數之疊合與區間極值 📍 對應本卷：第 4 題、第 6 題、第 12 題
當同一個角度的 $\sin x$ 與 $\cos x$ 以一次線性組合 $a\sin x + b\cos x$ 出現時，必須透過正餘弦疊合化為單一正弦函數，才能求其週期、振幅與極值。
📘 核心公式與觀念詳解
1. 正餘弦疊合公式：
　對於 $y = a\sin x + b\cos x$，提出振幅 $R = \sqrt{a^2 + b^2}$： $$y = \sqrt{a^2 + b^2}\left(\d\frac{a}{\sqrt{a^2 + b^2}}\sin x + \d\frac{b}{\sqrt{a^2 + b^2}}\cos x\right) = \sqrt{a^2 + b^2}\sin(x + \phi)$$ 　其中 $\cos\phi = \d\frac{a}{\sqrt{a^2 + b^2}}$，$\sin\phi = \d\frac{b}{\sqrt{a^2 + b^2}}$。
2. 最常考的兩組黃金疊合（必背）： $$\begin{aligned} \sin x \pm \cos x &= \sqrt{2}\sin\left(x \pm \d\frac{\pi}{4}\right) \quad (\text{振幅為 } \sqrt{2}) \\ \sqrt{3}\sin x \pm \cos x &= 2\sin\left(x \pm \d\frac{\pi}{6}\right) \quad (\text{振幅為 } 2) \end{aligned}$$
⚡ 學霸另解（移動視窗法求區間極值差——第 12 題關鍵）
在區間 $\left[\alpha , \alpha + \d\frac{\pi}{2}\right]$ 上求 $y = \sin x$ 的最大值 $A$ 與最小值 $B$ 之差 $A - B$ 的最大值：
・當視窗跨過波峰 $x = \d\frac{\pi}{2}$ 時，波峰附近曲線平緩，高低差 $A - B < 1$。
・當視窗落在單調遞減區間 $\left[\d\frac{\pi}{2} , \d\frac{3\pi}{2}\right]$ 時，$A - B = \sin\alpha - \sin\left(\alpha + \d\frac{\pi}{2}\right) = \sin\alpha - \cos\alpha = \sqrt{2}\sin\left(\alpha - \d\frac{\pi}{4}\right)$。
・幾何直覺：以反曲點 $x = \pi$ 為中心對稱取 $\left[\d\frac{3\pi}{4} , \d\frac{5\pi}{4}\right]$，曲線斜率最陡，高低落差最大為 $\d\frac{\sqrt{2}}{2} - \left(-\d\frac{\sqrt{2}}{2}\right) = \sqrt{2}$！
核心記憶口訣：先和角展開、再同類項合併、最後提出 $\sqrt{a^2+b^2}$ 疊合成單一 $\sin(x+\phi)$。
六、三角函數的圖形、伸縮平移與交點個數 📍 對應本卷：第 2 題、第 6 題、第 7 題
潮汐水深、摩天輪高度、交流電等週期現象皆以 $y = a\sin(bx + c) + d$ 建模。必須能從圖形的波峰與波谷瞬間讀出 $a, b, c, d$ 四個參數。
📘 核心公式與觀念詳解
1. 正弦函數模型 $y = a\sin(bx + c) + d$（設 $a, b > 0$）四大參數破譯法：
  • 振幅 $a$：$a = \d\frac{\text{最大值} - \text{最小值}}{2}$
  • 鉛直位移（中心平衡軸）$d$：$d = \d\frac{\text{最大值} + \text{最小值}}{2}$
  • 週期 $T$ 與頻率參數 $b$：$T = \text{相鄰兩波峰（或兩波谷）之水平距離} = \d\frac{2\pi}{b} \implies b = \d\frac{2\pi}{T}$
  • 相位常數 $c$：將函數提出 $b$ 寫成 $y = a\sin\left[b\left(x + \d\frac{c}{b}\right)\right] + d$，代表將 $y = a\sin bx + d$ 向右平移 $-\d\frac{c}{b}$ 單位；或直接代入圖形上已知的極值點 $(x_0, y_0)$ 搭配 $-\pi < c < 0$ 解出 $c$。
2. 函數變形對週期的影響：
　・基本週期：$y = \sin x, \cos x$ 週期為 $2\pi$；$y = \tan x$ 週期為 $\pi$。
　・水平伸縮：$y = \sin(kx + c)$ 週期為 $\d\frac{2\pi}{|k|}$。
　・整支取絕對值：$y = |\sin(kx + c)|$ 將下半波翻折至上半平面，正負波變成相同拱形，週期減半為 $\d\frac{\pi}{|k|}$。
⏱️ 學霸考場驗算：$y = A\sin(\omega x)$ 與過原點直線 $y = mx$ 交點個數 SOP
1. 先找振幅邊界：令 $|mx| \le A \implies |x| \le \d\frac{A}{|m|}$，超出此範圍必無交點。
2. 奇函數對稱秒殺偶數選項：因為兩圖形皆對稱於原點 $(0,0)$ 且必過 $(0,0)$，正負半軸交點成對出現，總交點數必為奇數 $(2k + 1)$！
3. 數正半軸波峰：若在 $[0 , x_{\max}]$ 內共有 $n$ 個完整週期（且第 $n$ 個波峰仍高於直線），則正半軸（不含原點）有 $2n - 1$ 個交點，總交點數 $= 2(2n - 1) + 1 = 4n - 1$ 個！
核心記憶口訣：$a$ 是半高差、$d$ 是平均高、$b = \d\frac{2\pi}{T}$、$c$ 用極值點代入反求最穩！
七、正弦定理、餘弦定理與角平分線性質 📍 對應本卷：第 10 題、第 11 題
解三角形的兩大支柱為正弦定理與餘弦定理。當題目出現「外接圓半徑／直徑」時必用正弦定理；當題目出現「角平分線與兩鄰邊」時則結合餘弦定理或角平分線公式。
📘 核心公式與觀念詳解
1. 正弦定理（求外接圓半徑 $R$ 或直徑 $2R$）： $$\d\frac{a}{\sin A} = \d\frac{b}{\sin B} = \d\frac{c}{\sin C} = 2R$$ 　注意：若題目求的是「外接圓直徑」，算出來的 $2R = \d\frac{c}{\sin C}$ 就是最終答案，切勿再除以 $2$！
2. 餘弦定理（已知兩邊與夾角求第三邊）： $$\overline{BC}^2 = \overline{AB}^2 + \overline{AC}^2 - 2\cdot\overline{AB}\cdot\overline{AC}\cos A$$ 3. 三角形內角平分線三大公式（設 $\overline{AD}$ 平分 $\angle A$，且 $\angle BAD = \angle CAD = \theta$）：
　・內分比性質：$\overline{BD} : \overline{CD} = \overline{AB} : \overline{AC} = c : b$。
　・面積和求角平分線長：由 $\triangle ABC = \triangle ABD + \triangle ACD$ 可導出 $\overline{AD} = \d\frac{2bc}{b + c}\cos\theta$。
　・角平分線長平方公式（學霸大招）： $$\overline{AD}^2 = \overline{AB}\cdot\overline{AC} - \overline{BD}\cdot\overline{CD}$$
核心記憶口訣：外接圓直徑 $2R = \d\frac{\overline{AB}}{\sin C}$；角平分線想「二倍角 $\cos 2\theta$」與「餘弦定理」。
八、圓與切線、互相垂直雙弦之幾何對稱性 📍 對應本卷：第 3 題、混合題第 1 & 2 小題
素養題與混合題最喜歡結合「圓的幾何性質」與「三角函數」。掌握圓外切線垂直半徑、圓內弦心距畢氏定理，以及圓的軸對稱性質，就能輕鬆拿滿手寫證明題的 10 分！
📘 核心公式與觀念詳解
1. 圓外一點作兩切線（第 3 題）：
　過圓外一點 $P$ 作圓 $O$ 的切線 $\overline{PA}, \overline{PB}$，則 $\angle OAP = \angle OBP = \d\frac{\pi}{2}$，四邊形 $OAPB$ 對角互補： $$\angle AOB = \pi - \angle APB$$ 2. 圓上點的座標與經典畢氏數組（混合題第 1 小題）：
　圓心在原點 $(0,0)$、半徑 $R = 25$ 的圓方程式為 $x^2 + y^2 = 25^2$。
　考場必背兩組斜邊為 $25$ 的直角三角形畢氏數： $$15^2 + 20^2 = 25^2 \quad (\text{即 } 3 : 4 : 5 \text{ 放大 } 5 \text{ 倍}) \quad , \quad 7^2 + 24^2 = 25^2$$ 　因此已知 $y = 15$ 立得 $x = 20$；已知 $x = 7$ 立得 $y = 24$。
3. 圓內互相垂直雙弦的對稱定理（混合題第 2 小題滿分證明架構）：
　若圓內兩弦 $\overline{AB} \perp \overline{CD}$，過圓心作平行兩弦的座標軸交圓於 $E, F, G, H$，由圓的軸對稱性必有： $$\overparen{AE} = \overparen{BG} \quad , \quad \overparen{CF} = \overparen{HD}$$ 　因此相對兩塊的圓弧總和恆為： $$\overparen{AC} + \overparen{BD} = \overparen{AC} + (\overparen{BG} + \overparen{GH} + \overparen{HD}) = (\overparen{AE} + \overparen{AC} + \overparen{CF}) + \overparen{GH} = \overparen{EF} + \overparen{GH} = \d\frac{\pi}{2}R + \d\frac{\pi}{2}R = \pi R$$ 　即相對兩圓弧之圓心角和恆為 $\pi$（弳），弧長總和恆等於半圓周長！
⚡ 學霸隱藏版彩蛋：$(3,4,5)$ 與 $(7,24,25)$ 的二倍角關係
在直角三角形 $(20, 15, 25)$ 中，$\tan\theta = \d\frac{3}{4}$，$\cos\theta = \d\frac{4}{5}$。
若將角度 $\theta$ 放大兩倍為 $2\theta$，則： $$\cos 2\theta = 2\cos^2\theta - 1 = 2\left(\d\frac{4}{5}\right)^2 - 1 = \d\frac{7}{25} \quad , \quad \sin 2\theta = 2\cdot\d\frac{3}{5}\cdot\d\frac{4}{5} = \d\frac{24}{25} \quad , \quad \tan 2\theta = \d\frac{24}{7}$$ 這正是另一個直角三角形 $(7, 24, 25)$ 的邊長比！記住「$(3,4,5)$ 的二倍角就是 $(7,24,25)$」，在混合題看到斜率 $\d\frac{24}{7}$ 與 $\d\frac{3}{4}$ 的夾角，就是 $2\theta - \theta = \theta$，1 秒鐘直接寫出 $\tan\angle AOC = \d\frac{3}{4}$！
核心記憶口訣：垂直雙弦對稱搬，對角圓弧湊半圓（$\angle AOC + \angle BOD = \pi$）；$(4,3,5)$ 二倍角即 $(7,24,25)$。
