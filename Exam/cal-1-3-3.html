🚕 計程車車資與高斯符號應用

📝 原題呈現

民國200年的計程車車資 $y$(元)隨里程 $x$(公里)而定，計算標準如下表所示：

里程
$x$公里		 $0 < x < 2$ $2 \leq x < 2.5$ $2.5 \leq x < 3$ $3 \leq x < 3.5$ $\cdots$
車資
$y$元		 100 110 120 130 $\cdots$

由上表可知未滿2公里車資為100元，之後每500公尺跳10元，未滿500公尺以500公尺計。則
(1)某人搭乘計程車里程為3公里，則應付車資多少元？
(2)若搭乘計程車里程為$x$公里，則應付車資$y = f(x)$，則$f(x) =$？

🚨 易錯盲點：區間邊界的「等號」歸屬

在計算第 (1) 小題時，很多同學會直觀地算「3公里比2公里多了兩個500公尺」，於是誤算為 $100 + 10 \times 2 = 120$。這犯了忽略計費起始點的錯誤。
請務必緊盯表格中的 $2 \leq x < 2.5$，這代表一達到 $2.0$ 公里時，車資就「已經」跳了第一次變成 $110$ 元。因此找 $x=3$ 對應的區間時，必須看清楚等號，它落在 $3 \leq x < 3.5$ 這一格。

💡 頂尖名師詳解

  • 解題 (1) - 查表對應法：
    題目欲求里程 $x = 3$ 公里時的車資。
    直接觀察題目給定的表格區間：
    $2.5 \leq x < 3$ 的車資為 $120$ 元（不包含 $x=3$）。
    $3 \leq x < 3.5$ 的車資為 $130$ 元（包含 $x=3$）。
    故 $x = 3$ 落在第四個區間，對應的車資為 $130$ 元。
  • 解題 (2) - 分段函數建構 (前段)：
    建立車資函數 $f(x)$ 必須根據題意分段處理。
    第一段為基本里程：當 $0 < x < 2$ 時，表格明確指出車資為固定值，因此： $$f(x) = 100 \quad (0 < x < 2)$$
  • 解題 (2) - 高斯函數建構 (後段)：
    當里程 $x \geq 2$ 時，每 $0.5$ 公里（500公尺）車資增加 $10$ 元。這是一個標準的「階梯函數」，我們可利用高斯符號 $[ \cdot ]$ 來處理。

    高斯符號 $[t]$ 的天性是「逢整數 $1$ 就跳階」。要讓函數在每經過 $0.5$ 單位時就產生跳動，我們必須進行單位換算：
    核心思考：在目前的里程 $x$ 當中，到底包含了「幾個」 $0.5$ 公里？
    計算「包含個數」直覺的數學運算就是除法，因此我們構造變數 $\d\frac{x}{0.5} = 2x$。

    這樣一來，當 $x$ 每增加 $0.5$，變數 $2x$ 就剛好增加 $1$，完美對接高斯符號的跳動週期！我們將其套用至表格中觀察：
    • 當 $x \in [2, 2.5)$ 時，$[2x] = [4, 5) = 4$，此時車資 $y = 110$
    • 當 $x \in [2.5, 3)$ 時，$[2x] = [5, 6) = 5$，此時車資 $y = 120$
    • 當 $x \in [3, 3.5)$ 時，$[2x] = [6, 7) = 6$，此時車資 $y = 130$
    我們發現車資 $y$ 與 $[2x]$ 之間呈現線性的規律。設 $y = 10 \cdot [2x] + k$，將 $([2x]=4, y=110)$ 代入，可得 $110 = 40 + k \implies k = 70$。
    因此，當 $x \geq 2$ 時，車資的通式為： $$f(x) = 10[2x] + 70 \quad (x \geq 2)$$
  • 整合答案：
    將前後兩段函數合併，即可得到完整的計程車資函數。

⚡ 學霸邏輯直推法（不需死背公式）

遇到這種「起跳＋後續累加」的題目，學霸腦中是這樣組裝公式的：
車資 = 基本費 + (跳表次數) $\times$ 每次跳表金額

1. 基本費： 毫無疑問是 $100$ 元。
2. 跳表次數： $x$ 超過 $2$ 公里後才開始算跳表。超出的距離是 $(x - 2)$。
依據前述「每 0.5 跳一次就除以 0.5」的邏輯，跳表次數為 $[ \d\frac{x-2}{0.5} ] + 1$ ，整理得 $[2x - 4] + 1$ 次。
（註：因為 $+1$ 是因為一達到 $2.0$ 就已經跳了第一次。而 $[2x - 4]$ 裡面的整數可直接移出，拆成 $[2x] - 4$）

3. 組合驗算：
當 $x \geq 2$ 時：
$f(x) = 100 + 10 \times (\text{跳表次數})$
$f(x) = 100 + 10 \times ([2x - 4] + 1)$
$f(x) = 100 + 10 \times ([2x] - 3)$
$f(x) = 100 + 10[2x] - 30 = \mathbf{10[2x] + 70}$

兩種思維殊途同歸，最後導出的式子極度簡潔完美！

🎯 最終答案

(1)

$130 \text{ 元}$

(2)

$$f(x) = \begin{cases} 100, & 0 < x < 2 \\ 10[2x] + 70, & x \geq 2 \end{cases}$$
