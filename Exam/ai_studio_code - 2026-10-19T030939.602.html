高中數學關鍵解題圖表：主題 08｜除法原理與綜合除法一次近似（公式 16、17）
16:9 精準座標資訊圖表
📌 原題條件：將 $f(x) = 2x^3 - 3x^2 + 4x - 1$ 化為 $p_3(x-1)^3 + p_2(x-1)^2 + p_1(x-1) + p_0$
🎯 求解目標：由連續綜合除法求展開係數，並求 $f(x)$ 在 $x=1$ 附近的一次近似切線 $(8)$
1. 題目條件與模型
  • 結合公式 16 除法與 17 綜合除法
  • 除法原理：$f=gQ+R$
  • 連續除以 $x-1$ 可得各階餘數
  • 末兩項 $p_1(x-1)+p_0$ 即為切線
2. 關鍵階段一：連續綜合除法
  • 第一層除以 $x-1$ 餘 $p_0 = 2$
  • 第二層除以 $x-1$ 餘 $p_1 = 4$
  • 第三層除以 $x-1$ 餘 $p_2 = 3$
  • 最左商數即首項係數 $p_3 = 2$
3. 關鍵階段二：讀取一次近似
  • 展開式末兩項：$p_1(x-1)+p_0$
  • 代入係數：$y = 4(x - 1) + 2$
  • 化簡得切線：$y = 4x - 2$
  • 大域特徵則為首項 $y = 2x^3$
4. 關鍵數據對照
  • 常數項：$p_0 = 2$
  • 一次項：$p_1 = 4$（切線斜率）
  • 近似值：$f(1.01) \approx 2.04$
  • 切線方程：$(8) : y = 4x - 2$
5. 核心公式與轉化
  • 餘式次數必小於除式次數
  • 缺項時綜合除法務必補 $0$
  • 除以 $ax-b$ 商式須再除以 $a$
  • 求 $f(1.01)$ 代入展開式最快
6. 易錯陷阱與心法
❌ 直覺陷阱：係數順序由底向上為 $p_3, p_2, p_1, p_0$
⚠️ 忽略機制：除式為 $ax-b$ 時，商式須再除以 $a$
💡 幾何直觀：末兩項 $p_1(x-k)+p_0$ 即 $x=k$ 處切線
高中數學關鍵解題圖表：主題 09｜餘式定理與因式定理進階解題（公式 18、19）
16:9 精準座標資訊圖表
📌 原題條件：多項式 $f(x)$ 有因式 $x - 1$，且除以 $x - 2$ 餘式為 $5$
🎯 求解目標：結合因式定理與餘式定理，求 $f(x)$ 除以 $(x-1)(x-2)$ 之餘式 $R(x) = (9)$
1. 題目條件與模型
  • 串聯公式 18 餘式與 19 因式定理
  • 有因式 $x-1$ 代表 $f(1) = 0$
  • 除以 $x-2$ 餘 $5$ 代表 $f(2) = 5$
  • 除式為二次，設餘式為 $ax+b$
2. 關鍵階段一：轉化函數點坐標
  • 因式定理：$x-k$ 整除 $\Leftrightarrow f(k)=0$
  • 由因式 $x-1$ 得第一點 $f(1) = 0$
  • 餘式定理：除以 $x-k$ 餘 $f(k)$
  • 由除以 $x-2$ 得第二點 $f(2) = 5$
3. 關鍵階段二：假設餘式解聯立
  • 列除法式：$f=(x-1)(x-2)Q+ax+b$
  • 代入 $x=1$ 得 $a + b = 0$
  • 代入 $x=2$ 得 $2a + b = 5$
  • 相減解得 $a = 5, b = -5$
4. 關鍵數據對照
  • 條件一：$f(1) = 0$
  • 條件二：$f(2) = 5$
  • 係數解：$a = 5, b = -5$
  • 所求餘式：$(9) = 5x - 5$
5. 核心公式與轉化
  • 一次除式 $ax-b$ 餘式為常數
  • 二次除式餘式設為 $ax+b$
  • 三次除式餘式設為 $ax^2+bx+c$
  • 整除即代表餘式恆等於 $0$
6. 易錯陷阱與心法
❌ 直覺陷阱：除以 $x+k$ 餘式為 $f(-k)$，注意正負變號
⚠️ 忽略機制：除式為二次時，餘式須設為 $ax+b$ 一次式
💡 幾何直觀：過 $(1,0)$ 與 $(2,5)$ 的直線即為所求餘式
高中數學關鍵解題圖表：主題 10｜二次函數頂點判別式與三次函數（公式 20、21、22）
16:9 精準座標資訊圖表
📌 原題條件：三次函數 $f(x) = x^3 - 3x^2 - 9x + 11$，其對稱中心為 $P(p, q)$
🎯 求解目標：結合配立方公式求對稱中心 $P(p, q)$ 坐標 $(10)$，並比較二次與三次圖形特徵
1. 題目條件與模型
  • 統整公式 20、21 二次與 22 三次
  • 二次頂點：$\displaystyle x = -\frac{b}{2a}$
  • 三次中心：$\displaystyle x = -\frac{b}{3a}$
  • 由標準式判別波浪或單調形狀
2. 關鍵階段一：二次頂點與判別式
  • 判別式：$D = b^2 - 4ac$
  • 頂點縱坐標：$\displaystyle y = -\frac{D}{4a}$
  • 當 $D > 0$ 時與 $x$ 軸交兩點
  • 當 $D < 0$ 時圖形恆正或恆負
3. 關鍵階段二：三次配立方求中心
  • 中心公式：$\displaystyle p = -\frac{b}{3a}$
  • 代入係數：$\displaystyle p = -\frac{-3}{3(1)} = 1$
  • 求縱坐標：$q = f(1) = 0$
  • 配立方得：$(x-1)^3 - 12(x-1)$
4. 關鍵數據對照
  • 中心橫坐標：$p = 1$
  • 中心縱坐標：$q = f(1) = 0$
  • 一次項係數：$k = -12$
  • 對稱中心：$(10) = (1, 0)$
5. 核心公式與轉化
  • 二次恆正條件：$a > 0$ 且 $D < 0$
  • 二次恆負條件：$a < 0$ 且 $D < 0$
  • 三次 $a>0$ 朝右上，$a<0$ 朝右下
  • 三次 $a, k$ 異號時呈波浪晃動
6. 易錯陷阱與心法
❌ 直覺陷阱：二次頂點分母為 $2a$，三次中心分母為 $3a$
⚠️ 忽略機制：二次函數恆正負代表不交 $x$ 軸，故 $D<0$
💡 幾何直觀：將三次函數平移 $(-p,-q)$ 即可消去二次項
