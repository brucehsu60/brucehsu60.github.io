高中數學關鍵解題圖表：主題 01｜等差數列一般項與前 n 項和（公式 1）
16:9 精準座標資訊圖表
📌 原題條件：等差數列 $\langle a_n \rangle$ 滿足 $a_3 = 7$、$a_9 = 19$，且前 $n$ 項和記為 $S_n$
🎯 求解目標：先求公差 $d$ 與一般項，再利用正中間項性質求前 $11$ 項和 $S_{11} = (1)$
1. 題目條件與模型
  • 對應公式 1 等差數列與求和
  • 已知第 $3$ 項 $a_3 = 7$
  • 已知第 $9$ 項 $a_9 = 19$
  • 奇數項和等於正中間項乘項數
2. 關鍵階段一：求公差與一般項
  • 兩項差：$a_9 - a_3 = 6d$
  • 代數值：$19 - 7 = 12$
  • 解得公差：$d = 2$，首項 $a_1 = 3$
  • 一般項：$a_n = 2n + 1$
3. 關鍵階段二：正中間項求和
  • 前 $11$ 項之正中間項為 $a_6$
  • 因 $3+9 = 2 \times 6$，得等差中項
  • 計算中項：$\displaystyle a_6 = \frac{7+19}{2} = 13$
  • 奇數項和：$S_{11} = 11 \times a_6 = 143$
4. 關鍵數據對照
  • 首項與公差：$a_1 = 3, d = 2$
  • 第 $11$ 項末項：$a_{11} = 23$
  • 正中間項：$a_6 = 13$
  • 前 $11$ 項總和：$(1) = 143$
5. 核心公式與轉化
  • 一般項：$a_n = a_1 + (n-1)d$
  • 梯形和：$\displaystyle S_n = \frac{n(a_1+a_n)}{2}$
  • 首項公差和：$\displaystyle n a_1 + \frac{n(n-1)}{2}d$
  • 項與和：$n \ge 2$ 時 $a_n = S_n - S_{n-1}$
6. 易錯陷阱與心法
❌ 直覺陷阱：由 $S_n-S_{n-1}$ 求 $a_n$ 僅限 $n \ge 2$
⚠️ 忽略機制：首項必用 $a_1 = S_1$ 獨立檢驗是否符合
💡 幾何直觀：知道 $a_3, a_9$ 免求首項，直接算中項 $a_6$
高中數學關鍵解題圖表：主題 02｜等比數列求和與複利本利和（公式 2、4）
16:9 精準座標資訊圖表
📌 原題條件：每年初存入 $10$ 萬元，年利率 $10\%$ 每年複利計息一次，已知 $1.1^5 \approx 1.61$
🎯 求解目標：結合複利公式與等比級數求和，求第 $5$ 年底之本利和總額 $(2)$ 萬元
1. 題目條件與模型
  • 結合公式 2 等比與公式 4 複利
  • 單筆本利和為 $P(1+r)^n$
  • 每年初存入構成 $5$ 筆複利
  • 加總即為公比 $1.1$ 之等比級數
2. 關鍵階段一：各期複利列式
  • 第 $5$ 年初存：$10 \times 1.1^1$
  • 第 $4$ 年初存：$10 \times 1.1^2$
  • 第 $1$ 年初存：$10 \times 1.1^5$
  • 首項 $a_1 = 11$，公比 $r = 1.1$
3. 關鍵階段二：等比級數求和
  • 求和公式：$\displaystyle S_n = \frac{a_1(r^n-1)}{r-1}$
  • 代數值：$\displaystyle S_5 = \frac{11(1.1^5-1)}{1.1-1}$
  • 代入 $1.1^5 \approx 1.61$ 化簡
  • 計算得：$110 \times 0.61 = 67.1$
4. 關鍵數據對照
  • 首項本利和：$a_1 = 11$ 萬元
  • 公比倍率：$r = 1.1$
  • 累積倍率：$1.1^5 \approx 1.61$
  • 第 $5$ 年底總額：$(2) = 67.1$
5. 核心公式與轉化
  • 等比一般項：$a_n = a_1 r^{n-1}$
  • 等比中項：$b^2 = ac \Rightarrow b = \pm\sqrt{ac}$
  • 當 $r = 1$ 時總和為 $S_n = n a_1$
  • 半年複利一次：期利率除以 $2$
6. 易錯陷阱與心法
❌ 直覺陷阱：年初存入年底結算，首項為 $P(1+r)$ 非 $P$
⚠️ 忽略機制：未知公比代公式前，須先討論 $r=1$ 特例
💡 幾何直觀：等比求和分子次方數 $n$ 代表「總項數」
高中數學關鍵解題圖表：主題 03｜三大連續整數級數求和公式（公式 3）
16:9 精準座標資訊圖表
📌 原題條件：級數 $S = 1 \times 2 + 2 \times 3 + 3 \times 4 + \cdots + 10 \times 11$，共 $10$ 項相乘相加
🎯 求解目標：先寫出第 $k$ 項一般式 $a_k$，再拆解套用平方和與一次和公式求總和 $S = (3)$
1. 題目條件與模型
  • 對應公式 3 三大級數求和公式
  • 觀察第 $k$ 項為 $a_k = k(k+1)$
  • 展開一般項得 $a_k = k^2 + k$
  • 拆成平方和與一次和分別計算
2. 關鍵階段一：計算平方和與一次和
  • 項數 $n = 10$ 代入求和公式
  • 一次和：$\displaystyle \sum k = \frac{10 \times 11}{2} = 55$
  • 平方和：$\displaystyle \frac{10 \times 11 \times 21}{6}$
  • 約分得平方和為 $385$
3. 關鍵階段二：合併求和與秒殺公式
  • 總和 $S = \sum k^2 + \sum k$
  • 代入數據：$S = 385 + 55 = 440$
  • 通分提出公因式可得秒殺公式
  • $\displaystyle \sum k(k+1) = \frac{n(n+1)(n+2)}{3}$
4. 關鍵數據對照
  • 前 $10$ 項一次和：$55$
  • 前 $10$ 項平方和：$385$
  • 前 $10$ 項立方和：$55^2 = 3025$
  • 本題所求總和：$(3) = 440$
5. 核心公式與轉化
  • 平方和第 $3$ 個因式為 $2n+1$
  • 立方和恰為一次和的完全平方
  • 分式型：$\displaystyle \frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$
  • 非從 $1$ 開始須用全段減前段
6. 易錯陷阱與心法
❌ 直覺陷阱：平方和公式分子為 $2n+1$，切勿寫成 $n+2$
⚠️ 忽略機制：公式 3 必須從 $1$ 開始加，缺前項須相減
💡 幾何直觀：熟記 $n=10$ 時平方和為 $385$，大考常直接用
高中數學關鍵解題圖表：主題 04｜均量、差量 Sxx 與標準差（公式 5、6、7）
16:9 精準座標資訊圖表
📌 原題條件：五筆一維數據 $2, 4, 6, 8, 10$，算術平均數為 $\mu$，離差平方和為 $S_{xx}$
🎯 求解目標：先求平均數 $\mu$ 與離差平方和 $S_{xx}$，再求母體標準差 $\sigma = (4)$
1. 題目條件與模型
  • 整合公式 5 均量、6 差量與 7 標準差
  • 算術平均數 $\mu$ 為數據重心
  • 離差平方和 $S_{xx} = \sum(x_i-\mu)^2$
  • 標準差 $\displaystyle \sigma = \sqrt{\frac{S_{xx}}{n}}$ 量測分散度
2. 關鍵階段一：求均量與差量 Sxx
  • 對稱等差數據平均數為正中間項
  • 得算術平均數 $\mu = 6$
  • 各點離差為 $-4, -2, 0, 2, 4$
  • 離差平方和：$16+4+0+4+16 = 40$
3. 關鍵階段二：求變異數與標準差
  • 變異數公式：$\displaystyle \sigma^2 = \frac{S_{xx}}{n}$
  • 代入得變異數：$\displaystyle \sigma^2 = \frac{40}{5} = 8$
  • 標準差公式：$\displaystyle \sigma = \sqrt{\frac{S_{xx}}{n}}$
  • 開根號得：$\sigma = \sqrt{8} = 2\sqrt{2}$
4. 關鍵數據對照
  • 算術平均數：$\mu = 6$
  • 離差平方和：$S_{xx} = 40$
  • 數據變異數：$\sigma^2 = 8$
  • 母體標準差：$(4) = 2\sqrt{2}$
5. 核心公式與轉化
  • 幾何平均數：$\sqrt[n]{x_1 x_2 \cdots x_n}$
  • 全距：最大減最小（易受極端值影響）
  • 四分位距：$Q_3 - Q_1$（抗極端值）
  • 平方和公式：$\sum x_i^2 = n(\sigma^2+\mu^2)$
6. 易錯陷阱與心法
❌ 直覺陷阱：成長率不可算術平均，須用幾何平均數
⚠️ 忽略機制：展開公式 $\sum x_i^2 - n\mu^2$ 勿漏乘 $n$
💡 幾何直觀：標準差愈小，代表數據愈集中於平均數
高中數學關鍵解題圖表：主題 05｜數據平移伸縮與標準化資料（公式 8、9）
16:9 精準座標資訊圖表
📌 原題條件：原數據 $X$ 平均數 $\mu_x = 60$、標準差 $\sigma_x = 8$，經線性調整為 $Y = -2X + 150$
🎯 求解目標：結合平移伸縮法則求新數據之平均數 $\mu_y$ 與標準差 $\sigma_y$，並算 $\mu_y + \sigma_y = (5)$
1. 題目條件與模型
  • 結合公式 8 平移伸縮與 9 標準化
  • 線性變換：$y_i = m x_i + d$
  • 均量跟著乘 $m$ 再加 $d$
  • 差量只受伸縮 $|m|$ 影響，與平移無關
2. 關鍵階段一：計算新平均數與標準差
  • 新平均：$\mu_y = -2\mu_x + 150$
  • 代入 $\mu_x = 60$ 得 $\mu_y = 30$
  • 新標準差：$\sigma_y = |-2|\sigma_x$
  • 代入 $\sigma_x = 8$ 得 $\sigma_y = 16$
3. 關鍵階段二：標準化資料性質
  • 標準化公式：$\displaystyle z_i = \frac{x_i - \mu}{\sigma}$
  • 相當於乘 $\displaystyle \frac{1}{\sigma}$ 再減 $\displaystyle \frac{\mu}{\sigma}$
  • 標準化後新平均數必為 $\mu_z = 0$
  • 標準化後新標準差必為 $\sigma_z = 1$
4. 關鍵數據對照
  • 新平均數：$\mu_y = 30$
  • 新標準差：$\sigma_y = 16$
  • 新變異數：$\sigma_y^2 = (-2)^2 \times 64 = 256$
  • 所求總和：$(5) = 30 + 16 = 46$
5. 核心公式與轉化
  • 中位數與眾數同享 $m x + d$ 規則
  • 全距與四分位距皆乘以 $|m|$
  • 變異數伸縮須乘平方倍 $m^2$
  • 若 $m < 0$ 中位數順序會反轉
6. 易錯陷阱與心法
❌ 直覺陷阱：標準差恆非負，乘負數 $m$ 務必加絕對值 $|m|$
⚠️ 忽略機制：平移常數 $+150$ 對標準差與全距毫無影響
💡 幾何直觀：任何數據標準化後，平均必為 $0$、標準差必為 $1$
高中數學關鍵解題圖表：主題 06｜相關係數與最小平方法迴歸直線（公式 10～13）
16:9 精準座標資訊圖表
📌 原題條件：二維數據滿足 $\mu_x = 4, \mu_y = 6$，且 $S_{xx} = 16, S_{yy} = 25, S_{xy} = 12$
🎯 求解目標：先求相關係數 $r$ 與迴歸直線方程式，再預測當 $x = 8$ 時之 $y$ 值 $(6)$
1. 題目條件與模型
  • 統整公式 10、11、12、13 二維分析
  • 離差乘積和 $S_{xy}$ 決定正負相關
  • 相關係數範圍為 $-1 \le r \le 1$
  • 迴歸直線必通過重心點 $(\mu_x, \mu_y)$
2. 關鍵階段一：計算相關係數 r
  • 公式：$\displaystyle r = \frac{S_{xy}}{\sqrt{S_{xx}}\sqrt{S_{yy}}}$
  • 代入：$\displaystyle r = \frac{12}{\sqrt{16} \times \sqrt{25}}$
  • 計算得：$\displaystyle r = \frac{12}{20} = 0.6$
  • 因 $r > 0$ 代表呈現正相關趨勢
3. 關鍵階段二：迴歸直線與預測
  • 迴歸斜率：$\displaystyle m = \frac{S_{xy}}{S_{xx}} = \frac{3}{4}$
  • 點斜式：$\displaystyle y - 6 = \frac{3}{4}(x - 4)$
  • 化簡得：$\displaystyle y = \frac{3}{4}x + 3$
  • 代入 $x = 8$ 預測得 $y = 9$
4. 關鍵數據對照
  • 相關係數：$r = 0.6$
  • 迴歸斜率：$\displaystyle m = \frac{3}{4} = 0.75$
  • 迴歸直線：$\displaystyle y = \frac{3}{4}x + 3$
  • 預測數值：$(6) = 9$
5. 核心公式與轉化
  • 展開式：$S_{xy} = \sum x_i y_i - n\mu_x\mu_y$
  • 標準化相關：$\displaystyle r = \frac{1}{n}\sum x_i' y_i'$
  • 線性變換後 $|r|$ 大小維持不變
  • 斜率 $m$ 與相關係數 $r$ 必同號
6. 易錯陷阱與心法
❌ 直覺陷阱：迴歸斜率分母是 $S_{xx}$ 與 $\sigma_x$，切勿放反
⚠️ 忽略機制：水平或鉛直排列之散佈圖，相關係數 $r=0$
💡 幾何直觀：標準化後迴歸線必過原點，即 $y' = r \cdot x'$
高中數學關鍵解題圖表：主題 07｜邏輯敘述、充要條件與集合子集（公式 14～16）
16:9 精準座標資訊圖表
📌 原題條件：設集合 $A = \{1, 2\}$、$B = \{1, 2, 3, 4, 5\}$，且有限集合 $C$ 滿足 $A \subset C \subset B$
🎯 求解目標：判別 $x \in A$ 為 $x \in B$ 之何種條件，並求滿足包含關係之集合 $C$ 個數 $(7)$
1. 題目條件與模型
  • 結合公式 14、15 邏輯與 16 子集
  • 小範圍推大範圍：$A \subset B$
  • 若 $P \Rightarrow Q$ 則 $P$ 為充分條件
  • 集合 $C$ 必含 $1, 2$，可選 $3, 4, 5$
2. 關鍵階段一：充分與必要判別
  • 因為 $A \subset B$，故 $x \in A \Rightarrow x \in B$
  • 箭頭左方 $x \in A$ 稱為充分條件
  • 箭頭右方 $x \in B$ 稱為必要條件
  • 原命題與逆否命題「非 $Q \Rightarrow$ 非 $P$」同義
3. 關鍵階段二：子集個數計算
  • 公式 16：子集總數為 $2^{n(A)}$
  • 元素 $1, 2$ 必在 $C$ 中（各 $1$ 種選擇）
  • 元素 $3, 4, 5$ 可選可不選（各 $2$ 種）
  • 集合 $C$ 個數：$1^2 \times 2^3 = 8$ 個
4. 關鍵數據對照
  • 集合 $A$ 子集數：$2^2 = 4$ 個
  • 集合 $B$ 子集數：$2^5 = 32$ 個
  • 自由元素個數：$5 - 2 = 3$ 個
  • 滿足之集合 $C$ 個數：$(7) = 8$
5. 核心公式與轉化
  • 元素與集合用屬於記號 $x \in A$
  • 子集與集合用包含記號 $A \subset B$
  • 空集合 $\varnothing$ 為任意集合的子集
  • 雙向互推 $P \Leftrightarrow Q$ 互為充要條件
6. 易錯陷阱與心法
❌ 直覺陷阱：逆命題「若 $Q$ 則 $P$」不一定與原命題同真假
⚠️ 忽略機制：若題目要求「真子集」，須扣除本身集合減 $1$
💡 幾何直觀：小範圍可推大範圍，故小集合為大集合充分條件
高中數學關鍵解題圖表：主題 08｜集合運算、笛摩根律與取捨原理（公式 17～19）
16:9 精準座標資訊圖表
📌 原題條件：在 $1$ 到 $100$ 的正整數中，設 $A$ 為 $2$ 的倍數集合、$B$ 為 $3$ 的倍數集合
🎯 求解目標：結合笛摩根律與取捨原理，求既不是 $2$ 的倍數也不是 $3$ 的倍數之個數 $(8)$
1. 題目條件與模型
  • 串聯公式 17 集合、18 笛摩根與 19 取捨
  • 宇集個數：$n(U) = 100$
  • 所求為 $n(A' \cap B')$
  • 由笛摩根律轉為 $n(U) - n(A \cup B)$
2. 關鍵階段一：取捨原理求聯集
  • $2$ 的倍數：$n(A) = \lfloor \frac{100}{2} \rfloor = 50$
  • $3$ 的倍數：$n(B) = \lfloor \frac{100}{3} \rfloor = 33$
  • $6$ 的倍數：$n(A \cap B) = \lfloor \frac{100}{6} \rfloor = 16$
  • 聯集：$50 + 33 - 16 = 67$
3. 關鍵階段二：笛摩根律求補集
  • 笛摩根律：$A' \cap B' = (A \cup B)'$
  • 代表宇集扣除聯集區域
  • 列式：$n(U) - n(A \cup B)$
  • 計算得：$100 - 67 = 33$
4. 關鍵數據對照
  • 兩集合個數：$n(A)=50, n(B)=33$
  • 共同交集數：$n(A \cap B) = 16$
  • 聯集總個數：$n(A \cup B) = 67$
  • 皆非之個數：$(8) = 33$
5. 核心公式與轉化
  • 差集定義：$A - B = A \cap B'$
  • 差集個數：$n(A) - n(A \cap B)$
  • 補集個數：$n(A') = n(U) - n(A)$
  • 至少其一即求聯集 $n(A \cup B)$
6. 易錯陷阱與心法
❌ 直覺陷阱：差集個數是 $n(A)-n(A\cap B)$ 而非 $n(A)-n(B)$
⚠️ 忽略機制：兩集合交集須取最小公倍數 $\text{lcm}(a,b)$ 而非直接相乘
💡 幾何直觀：遇到「皆非」必用笛摩根律轉為「全體減聯集」

📌 原題條件：一、將 $a, a, a, b, c, c$ 六字母全取排成一列；二、多項式 $\left(x^2 + \frac{2}{x}\right)^6$ 展開式
🎯 求解目標：求相同物直線排列數 $M$，並求二項式展開中 $x^3$ 項係數 $(9)$
1. 題目條件與模型
  • 統整公式 20～24 排列組合與二項式
  • 相異物排列 $P^n_r$ 考慮順序
  • 組合選取 $C^n_r$ 不考慮順序
  • 二項式一般項為 $C^n_r a^{n-r} b^r$
2. 關鍵階段一：相同物排列與巴斯卡
  • 共有 $3$ 個 $a$、$1$ 個 $b$、$2$ 個 $c$
  • 相同物視為無順序須除以階乘
  • 排列數：$\displaystyle M = \frac{6!}{3! \times 2!} = 60$
  • 巴斯卡口訣：上標同加一、下標取大
3. 關鍵階段二：二項式定理求係數
  • 一般項：$C^6_r (x^2)^{6-r} (2x^{-1})^r$
  • 整理次方：$C^6_r \cdot 2^r \cdot x^{12-3r}$
  • 令次方 $12 - 3r = 3 \Rightarrow r = 3$
  • 求係數：$C^6_3 \times 2^3 = 20 \times 8 = 160$
4. 關鍵數據對照
  • 相同物排列數：$M = 60$ 種
  • 命中項次指標：$r = 3$
  • 組合數與倍率：$C^6_3 = 20, 2^3 = 8$
  • 所求 $x^3$ 項係數：$(9) = 160$
5. 核心公式與轉化
  • 組合總和：$C^n_0 + C^n_1 + \cdots + C^n_n = 2^n$
  • 奇偶交錯：$C^n_0 - C^n_1 + C^n_2 - \cdots = 0$
  • 奇數項和等於偶數項和 $= 2^{n-1}$
  • 求各項係數總和：直接令 $x = y = 1$
6. 易錯陷阱與心法
❌ 直覺陷阱：二項式求係數時，切勿漏乘括號內的常數次方 $2^r$
⚠️ 忽略機制：組合級數若缺首項 $C^n_0$，答案須減去 $1$ 即 $2^n-1$
💡 幾何直觀：棋盤方格走捷徑問題，本質即為「相同物排列」
高中數學關鍵解題圖表：主題 10｜銳角三角比、極坐標與廣義角（公式 25～27）
16:9 精準座標資訊圖表
📌 原題條件：有向角 $\theta$ 終邊通過第二象限點 $P(-3, 4)$，且另一點 $Q$ 極坐標為 $[6, 120^\circ]$
🎯 求解目標：先求點 $P$ 廣義角三角比 $\sin\theta + \cos\theta = (10)$，再將極坐標 $Q$ 化為直角坐標
1. 題目條件與模型
  • 結合公式 25 銳角、26 極坐標與 27 廣義角
  • 逆時針旋轉為正向角，順時針為負
  • 距離半徑：$r = \sqrt{a^2+b^2} > 0$
  • 廣義角定義：$\displaystyle \sin\theta = \frac{y}{r}, \cos\theta = \frac{x}{r}$
2. 關鍵階段一：廣義角三角比計算
  • 由 $P(-3, 4)$ 得 $r = \sqrt{(-3)^2+4^2} = 5$
  • 正弦值：$\displaystyle \sin\theta = \frac{y}{r} = \frac{4}{5}$
  • 餘弦值：$\displaystyle \cos\theta = \frac{x}{r} = -\frac{3}{5}$
  • 相加得：$\displaystyle \sin\theta + \cos\theta = \frac{1}{5}$
3. 關鍵階段二：極坐標轉直角坐標
  • 極坐標 $[r, \theta]$ 轉換公式為 $(r\cos\theta, r\sin\theta)$
  • 代入 $r = 6, \theta = 120^\circ$
  • 橫坐標：$x = 6\cos 120^\circ = -3$
  • 縱坐標：$y = 6\sin 120^\circ = 3\sqrt{3}$
4. 關鍵數據對照
  • 正弦與餘弦：$\displaystyle \sin\theta = \frac{4}{5}, \cos\theta = -\frac{3}{5}$
  • 正切斜率：$\displaystyle \tan\theta = \frac{y}{x} = -\frac{4}{3}$
  • 點 $Q$ 直角坐標：$(-3, 3\sqrt{3})$
  • 所求三角比和：$\displaystyle (10) = \frac{1}{5}$
5. 核心公式與轉化
  • 銳角正弦：$\displaystyle \sin\theta = \frac{\text{對邊}}{\text{斜邊}}$
  • 銳角餘弦：$\displaystyle \cos\theta = \frac{\text{鄰邊}}{\text{斜邊}}$
  • 銳角正切：$\displaystyle \tan\theta = \frac{\text{對邊}}{\text{鄰邊}}$
  • 同界角性質：相差 $360^\circ \times k$ 三角比相同
6. 易錯陷阱與心法
❌ 直覺陷阱：距離半徑 $r = \sqrt{a^2+b^2}$ 永遠為正數，切勿帶負號
⚠️ 忽略機制：極坐標 $[r,\theta]$ 用方括號表示，順序為先長 $r$ 後角 $\theta$
💡 幾何直觀：$\sin\theta$ 看 $y$ 坐標上下正負，$\cos\theta$ 看 $x$ 坐標左右正負
高中數學關鍵解題圖表：主題 11｜商數平方關係、角度變換與反三角（公式 28、29、34）
16:9 精準座標資訊圖表
📌 原題條件：已知銳角 $\theta$ 滿足 $\sin\theta + \cos\theta = \frac{7}{5}$，且反餘弦角 $\alpha = \cos^{-1}\left(-\frac{1}{2}\right)$
🎯 求解目標：先由平方關係求 $\sin\theta\cos\theta = (11)$，再決定反三角函數 $\alpha$ 之角度
1. 題目條件與模型
  • 整合公式 28 恆等式、29 變換與 34 反三角
  • 商數關係：$\displaystyle \tan\theta = \frac{\sin\theta}{\cos\theta}$
  • 平方關係：$\sin^2\theta + \cos^2\theta = 1$
  • 看到和與積互求，優先將兩邊平方
2. 關鍵階段一：平方關係求乘積
  • 將 $\sin\theta+\cos\theta = \frac{7}{5}$ 兩邊平方
  • 展開：$\sin^2\theta+\cos^2\theta+2\sin\theta\cos\theta = \frac{49}{25}$
  • 代入平方和為 $1$：$1 + 2\sin\theta\cos\theta = \frac{49}{25}$
  • 移項除以 $2$ 得：$\displaystyle \sin\theta\cos\theta = \frac{12}{25}$
3. 關鍵階段二：反三角函數範圍判別
  • 反餘弦定義域：$0^\circ \le \alpha \le 180^\circ$
  • 已知 $\cos\alpha = -\frac{1}{2} < 0$
  • 落在第二象限補角區間
  • 得唯一角度：$\alpha = 180^\circ - 60^\circ = 120^\circ$
4. 關鍵數據對照
  • 兩數之和：$\displaystyle \sin\theta + \cos\theta = \frac{7}{5}$
  • 兩數之差：$\displaystyle |\sin\theta - \cos\theta| = \frac{1}{5}$
  • 反餘弦角：$\cos^{-1}\left(-\frac{1}{2}\right) = 120^\circ$
  • 所求乘積：$\displaystyle (11) = \frac{12}{25}$
5. 核心公式與轉化
  • 齊次分式同除以 $\cos\theta$ 轉為 $\tan\theta$
  • $\displaystyle \tan\theta + \frac{1}{\tan\theta} = \frac{1}{\sin\theta\cos\theta}$
  • $(\sin\theta-\cos\theta)^2 = 1 - 2\sin\theta\cos\theta$
  • 口訣：奇變偶不變、正負看象限
6. 易錯陷阱與心法
❌ 直覺陷阱：上標 $\sin^{-1}k$ 代表「反三角角度」而非倒數 $\frac{1}{\sin k}$
⚠️ 忽略機制：負數之 $\sin^{-1}$ 取負銳角，但 $\cos^{-1}$ 須取鈍角
💡 幾何直觀：補角相加 $180^\circ$，僅 $\sin$ 保持同號，餘皆變號
高中數學關鍵解題圖表：主題 12｜正弦、餘弦、中線定理與面積公式（公式 30～33）
16:9 精準座標資訊圖表
📌 原題條件：$\triangle ABC$ 三邊長為 $a = 7, b = 5, c = 8$，設外接圓半徑為 $R$、內切圓半徑為 $r$
🎯 求解目標：先由餘弦定理求 $\angle A$，再由面積與正弦定理求面積 $\triangle$、$R$ 與 $r = (12)$
1. 題目條件與模型
  • 統整公式 30 正弦、31 餘弦、32 中線、33 面積
  • 已知三邊長（SSS）優先用餘弦定理
  • 面積可用兩邊夾角或海龍公式求得
  • 由 $\triangle = rs$ 與正弦定理求 $r, R$
2. 關鍵階段一：餘弦定理與正弦求 R
  • 餘弦公式：$\displaystyle \cos A = \frac{b^2+c^2-a^2}{2bc}$
  • 代入三邊：$\displaystyle \cos A = \frac{25+64-49}{80} = \frac{1}{2}$
  • 得 $\angle A = 60^\circ$，故 $\displaystyle \sin A = \frac{\sqrt{3}}{2}$
  • 正弦定理：$\displaystyle 2R = \frac{a}{\sin A} = \frac{14}{\sqrt{3}}$
3. 關鍵階段二：面積公式求內切圓 r
  • 半周長：$\displaystyle s = \frac{7+5+8}{2} = 10$
  • 海龍面積：$\sqrt{10(3)(5)(2)} = 10\sqrt{3}$
  • 利用內切圓面積公式：$\triangle = r \cdot s$
  • 代入得：$10\sqrt{3} = 10r \Rightarrow r = \sqrt{3}$
4. 關鍵數據對照
  • 三角形面積：$\triangle = 10\sqrt{3}$
  • 外接圓半徑：$\displaystyle R = \frac{7\sqrt{3}}{3}$
  • 半周長數值：$s = 10$
  • 內切圓半徑：$(12) = \sqrt{3}$
5. 核心公式與轉化
  • 正弦比例：$a : b : c = \sin A : \sin B : \sin C$
  • 外接圓面積式：$\displaystyle \triangle = \frac{abc}{4R}$
  • 中線定理：$\overline{AB}^2+\overline{AC}^2 = 2(\overline{AM}^2+\overline{MB}^2)$
  • 鈍角判別：最大邊平方 $>$ 另兩邊平方和
6. 易錯陷阱與心法
❌ 直覺陷阱：正弦定理比值等於直徑 $2R$，求半徑 $R$ 務必除以 $2$
⚠️ 忽略機制：邊比等於正弦比 $\sin A:\sin B:\sin C$，非角度比 $A:B:C$
💡 幾何直觀：求外接圓 $R$ 用正弦定理，求內切圓 $r$ 必用面積 $\triangle = rs$
