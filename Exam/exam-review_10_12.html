高中數學 A 關鍵解題圖表：三角函數動區間極值與移動視窗法 16:9 精準座標資訊圖表

📌 原題條件：已知函數 $y = \sin x$，$\alpha \le x \le \alpha + \dfrac{\pi}{2}$，其中 $0 < \alpha < \pi$。 🎯 求解目標：設區間內最大值為 $A$、最小值為 $B$，求高低落差 $A - B$ 之最大值 $\sqrt{(12)}$。
1. 題目條件與模型
  • 目標函數：$y = \sin x$ 正弦波
  • 移動視窗寬度固定為 $\dfrac{\pi}{2}$
  • 左端點範圍：$0 < \alpha < \pi$
  • 右端點範圍：$\dfrac{\pi}{2} < \alpha + \dfrac{\pi}{2} < \dfrac{3\pi}{2}$
  • $(0,\pi)$ 在 $x$ 軸上；$(\pi,\frac{3\pi}{2})$ 在軸下
2. 關鍵階段一：跨波峰區間
  • 當 $0 < \alpha < \dfrac{\pi}{2}$ 時跨過山頂
  • 區間包住波峰 $x = \dfrac{\pi}{2}$
  • 最大值釘在山頂：$A = 1$
  • 兩端點皆在 $x$ 軸上：$B > 0$
  • 高低落差：$0 < A - B < 1$
3. 關鍵階段二：純遞減區間
  • 當 $\dfrac{\pi}{2} \le \alpha < \pi$ 全程遞減
  • 左端點最高：$A = \sin\alpha$
  • 右端點最低：$B = \cos\alpha$
  • 反曲點 $(\pi,0)$ 斜率最陡峭
  • 取 $\left[\dfrac{3\pi}{4}, \dfrac{5\pi}{4}\right]$ 落差達 $\sqrt{2}$
4. 關鍵數據對照
  • $\alpha = \dfrac{\pi}{4} \Rightarrow A-B = 1 - \dfrac{\sqrt{2}}{2}$
  • $\alpha = \dfrac{\pi}{2} \Rightarrow A=1, B=0, \text{差}=1$
  • $\alpha = \dfrac{3\pi}{4} \Rightarrow A=\dfrac{\sqrt{2}}{2}, B=-\dfrac{\sqrt{2}}{2}$
  • 最大高低落差：$A - B = \sqrt{2}$
  • 對應題目根號格號：$(12) = 2$
5. 核心公式與轉化
  • 誘導化簡：$\sin\!\left(\alpha+\dfrac{\pi}{2}\right)=\cos\alpha$
  • 落差函數：$g(\alpha)=\sin\alpha-\cos\alpha$
  • 正餘弦疊合提出振幅 $\sqrt{2}$：
  • $g(\alpha)=\sqrt{2}\sin\!\left(\alpha-\dfrac{\pi}{4}\right)$
  • 當 $\alpha=\dfrac{3\pi}{4}$ 時 $\sin\dfrac{\pi}{2}=1$ 最大
6. 易錯陷阱與心法
❌
直覺陷阱：誤拿兩端點直接相減，忽略波峰在區間內
⚠️
忽略機制：未以 $\alpha = \dfrac{\pi}{2}$ 分段討論極值公式變化
💡
幾何直觀：視窗對稱跨過反曲點 $(\pi, 0)$ 斜率最陡
🎯 核心結論
破題關鍵：將寬度 $\dfrac{\pi}{2}$ 的視窗對稱跨在 $y=\sin x$ 下降最陡的反曲點 $(\pi,0)$ 左右，即區間取 $\left[\dfrac{3\pi}{4}, \dfrac{5\pi}{4}\right]$ 時，最大高低差 $A - B = \sqrt{2}$，故格號 (12) 填 2。
12. 已知函數 $y = \sin x$，$\alpha \le x \le \alpha + \d\frac{\pi}{2}$，其中 $0 < \alpha < \pi$。若 $y$ 的最大值為 $A$，最小值為 $B$，則 $A - B$ 之最大值為 $\sqrt{\text{(12)}}$。
📘 正規詳解（分段討論＋正餘弦疊合法）
以波峰 $x = \d\frac{\pi}{2}$ 為界，分兩階段討論寬度為 $\d\frac{\pi}{2}$ 的閉區間 $\left[\alpha , \alpha + \d\frac{\pi}{2}\right]$：
  • 階段一（跨波峰區間）：當 $0 < \alpha < \d\frac{\pi}{2}$ 時，右端點範圍為 $\d\frac{\pi}{2} < \alpha + \d\frac{\pi}{2} < \pi$。
    此時區間包含波峰 $x = \d\frac{\pi}{2}$，且整個區間皆落在 $(0, \pi)$ 的 $x$ 軸上方（$y > 0$），故： $$A = \sin\d\frac{\pi}{2} = 1 \quad , \quad B = \min\left\{\sin\alpha , \sin\left(\alpha + \d\frac{\pi}{2}\right)\right\} > 0$$ 因此高低落差必滿足 $0 < A - B < 1$。
  • 階段二（純遞減區間）：當 $\d\frac{\pi}{2} \le \alpha < \pi$ 時，右端點範圍為 $\pi \le \alpha + \d\frac{\pi}{2} < \d\frac{3\pi}{2}$。
    在區間 $\left[\d\frac{\pi}{2} , \d\frac{3\pi}{2}\right]$ 上，$y = \sin x$ 為嚴格遞減函數，故最大值發生於左端點、最小值發生於右端點： $$A = \sin\alpha \quad , \quad B = \sin\left(\alpha + \d\frac{\pi}{2}\right) = \cos\alpha$$ 利用正餘弦疊合求 $A - B$ 的最大值： $$A - B = \sin\alpha - \cos\alpha = \sqrt{2}\left(\sin\alpha\cos\d\frac{\pi}{4} - \cos\alpha\sin\d\frac{\pi}{4}\right) = \sqrt{2}\sin\left(\alpha - \d\frac{\pi}{4}\right)$$ 因為 $\d\frac{\pi}{2} \le \alpha < \pi \implies \d\frac{\pi}{4} \le \alpha - \d\frac{\pi}{4} < \d\frac{3\pi}{4}$，當 $\alpha = \d\frac{3\pi}{4}$ 時，$\sqrt{2}\sin\left(\alpha - \d\frac{\pi}{4}\right)$ 有最大值 $\sqrt{2}\sin\d\frac{\pi}{2} = \sqrt{2}$。
綜合階段一與階段二，得 $A - B$ 之最大值為 $\sqrt{2}$，故 $\text{(12)} = 2$。
⚡ 學霸另解（移動視窗與反曲點對稱秒殺法）
將區間 $\left[\alpha , \alpha + \d\frac{\pi}{2}\right]$ 視為寬度固定為 $\d\frac{\pi}{2}$ 的移動視窗。欲使視窗內的鉛直落差 $A - B$ 最大，視窗必須框在正弦波斜率最陡峭的反曲點 $( \pi , 0 )$ 正中央！
由對稱性，將視窗自 $x = \pi$ 向左右各張開 $\d\frac{\pi}{4}$，即取區間 $\left[\pi - \d\frac{\pi}{4} , \pi + \d\frac{\pi}{4}\right] = \left[\d\frac{3\pi}{4} , \d\frac{5\pi}{4}\right]$（此時 $\alpha = \d\frac{3\pi}{4} \in (0, \pi)$）： $$A - B = \sin\d\frac{3\pi}{4} - \sin\d\frac{5\pi}{4} = \d\frac{\sqrt{2}}{2} - \left(-\d\frac{\sqrt{2}}{2}\right) = \sqrt{2}$$
⏱️ 學霸考場驗算（端點特值快速夾擊）
在考場上花 5 秒鐘代入兩個指標角度驗證：
・代 $\alpha = \d\frac{\pi}{2}$（區間 $\left[\d\frac{\pi}{2}, \pi\right]$）：$A - B = 1 - 0 = 1$，故最大值必大於 $1$。
・代 $\alpha = \d\frac{3\pi}{4}$（區間 $\left[\d\frac{3\pi}{4}, \d\frac{5\pi}{4}\right]$）：$A - B = \d\frac{\sqrt{2}}{2} - \left(-\d\frac{\sqrt{2}}{2}\right) = \sqrt{2} \approx 1.414 > 1$，瞬間確認答案為 $\sqrt{2}$！
最終答案：$\sqrt{2}$（即格號 (12) 填 $2$）
