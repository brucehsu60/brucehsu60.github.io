1. 割線斜率、切線斜率與導數 $f'(a)$ 的極限定義（對應中叢 p.2-1 重點1～3、p.2-1～2-4 第1～3, 6, 9～12題）
📘 【核心定理】由割線逼近切線與導數的兩種極限表示法（對應中叢 p.2-1 重點1～3）
  • 割線與平均變化率：曲線上兩點 $A(x_1, f(x_1))$、$B(x_2, f(x_2))$ 的割線 $\overleftrightarrow{AB}$ 斜率即為平均變化率： \[ \color{#2563eb}{\frac{\Delta y}{\Delta x} = \frac{f(x_2)-f(x_1)}{x_2-x_1}} \]
  • 導數定義與切線方程式：當動點 $x \to a$（或增量 $h = x-a \to 0$）時，割線極限即為點 $A(a, f(a))$ 的切線斜率（瞬時變化率）$m = f'(a)$： \[ \color{#dc2626}{f'(a) = \lim_{x \to a} \frac{f(x)-f(a)}{x-a} = \lim_{h \to 0} \frac{f(a+h)-f(a)}{h}} \] 若極限存在，稱 $f(x)$ 在 $x=a$ 處可微分，且以 $A(a, f(a))$ 為切點的切線方程式為 $y = f'(a)(x-a) + f(a)$。

⚡ 【範例 1-1】利用導數定義（因式分解與有理化）求切線與導數（對應中叢 p.2-1 第1～2題、p.2-2 第3, 6題、p.2-3 第10題）
題目 A（多項式定義法，中叢 p.2-1 第1題）：設 $f(x)=x^3+x$，由定義求 $f'(1)$ 並寫出以 $P(1,2)$ 為切點的切線。
精解 A：$\color{#2563eb}{f'(1) = \lim_{x\to 1}\d\frac{(x^3+x)-2}{x-1} = \lim_{x\to 1}\d\frac{(x-1)(x^2+x+2)}{x-1} = 1+1+2 = \color{#dc2626}{4}}$。切線為 $\color{#dc2626}{y=4(x-1)+2}$。
題目 B（根式有理化，中叢 p.2-2 第3題）：設 $f(x)=\sqrt{x+5}$，由定義求 $f'(-1)$ 並寫出以 $P(-1,2)$ 為切點的切線。
精解 B：分子分母同乘共軛根式 $(\sqrt{x+5}+2)$：
$\color{#2563eb}{f'(-1) = \lim_{x\to -1}\d\frac{\sqrt{x+5}-2}{x+1} = \lim_{x\to -1}\d\frac{(x+5)-4}{(x+1)(\sqrt{x+5}+2)} = \lim_{x\to -1}\d\frac{1}{\sqrt{x+5}+2} = \color{#dc2626}{\d\frac{1}{4}}}$。切線為 $\color{#dc2626}{y=\d\frac{1}{4}(x+1)+2}$。
題目 C（含因式之分式函數，中叢 p.2-3 第10(2)題）：設 $f(x)=\d\frac{(x-1)(x-2)(x-3)}{x-4}$，利用定義求 $f'(1)$。
精解 C：先觀察發現 $f(1)=0$！直接代入導數定義約掉 $(x-1)$（千萬別用商的微分硬展開！）：
$\color{#2563eb}{f'(1) = \lim_{x\to 1}\d\frac{f(x)-0}{x-1} = \lim_{x\to 1}\d\frac{(x-2)(x-3)}{x-4} = \d\frac{(-1)(-2)}{-3} = \color{#dc2626}{-\d\frac{2}{3}}}$。
範例答案：題A：$4$，切線 $y=4(x-1)+2$；題B：$\d\frac{1}{4}$，切線 $y=\d\frac{1}{4}(x+1)+2$；題C：$-\d\frac{2}{3}$

⚡ 【學霸考場秒殺技 1：乘法微分「遮蓋法／留一法」完整推導】（僅供選擇／填充題秒殺與驗算，計算題若要求「由定義求」請勿使用｜對應中叢 p.2-3 第10(2)(3)題、p.2-6 第1(4)～(7)題） ■ 中叢 p.2-3 第10(2)題完整步驟：設 $f(x)=\d\frac{(x-1)(x-2)(x-3)}{x-4}$，求 $f'(1)$。
1. 拆解因式：將原函數拆解為 $f(x) = (x-1)\cdot g(x)$，其中 $g(x) = \d\frac{(x-2)(x-3)}{x-4}$。
2. 利用乘法微分法則（前微後不微＋前不微後微）： \[ f'(x) = (x-1)'\cdot g(x) + (x-1)\cdot g'(x) = 1\cdot g(x) + (x-1)\cdot g'(x) \] 3. 代入 $x=1$（後項因 $(1-1)=0$ 直接歸零，完全不需算出複雜的 $g'(x)$！）： \[ f'(1) = 1\cdot g(1) + (1-1)\cdot g'(1) = g(1) + 0 = \frac{(1-2)(1-3)}{1-4} = \frac{(-1)(-2)}{-3} = \color{#dc2626}{-\frac{2}{3}} \]
■ 中叢 p.2-3 第10(3)題完整步驟：設 $f(x)=\d\frac{(x+1)(x-3)}{x-1}$，求 $f'(3)$。
1. 拆解因式：令 $f(x) = (x-3)\cdot h(x)$，其中 $h(x) = \d\frac{x+1}{x-1}$。
2. 利用乘法微分法則：$f'(x) = (x-3)'\cdot h(x) + (x-3)\cdot h'(x) = 1\cdot h(x) + (x-3)\cdot h'(x)$。
3. 代入 $x=3$（後項直接歸零）：$f'(3) = h(3) + (3-3)\cdot h'(3) = \d\frac{3+1}{3-1} = \d\frac{4}{2} = \color{#dc2626}{2}$。
💡 考場口訣：求一次因式根 $x=a$ 處的導數 $f'(a)$，直接用手指把 $(x-a)$ 遮起來，將 $x=a$ 代入剩下的部分 $g(a)$ 即得答案！
🚀 【學霸考場秒殺技 2：羅必達法則 (L'Hôpital's Rule)】（高三選修微積分／大考驗算利器，計算題若要求「由定義求」請勿使用｜對應中叢 p.2-2 第3題、p.2-4 第12題） 當求極限 $\lim_{x\to a}\d\frac{f(x)}{g(x)}$ 代入 $x=a$ 出現 $\d\frac{0}{0}$ 不定型，且分子分母在 $x=a$ 附近可微（$g'(a)\neq 0$）時，可直接將分子、分母各自對 $x$ 微分再代入（注意：是上下各自獨立微分，不是商的微分公式！）： \[ \color{#dc2626}{\lim_{x\to a}\frac{f(x)}{g(x)} \,\overset{\frac{0}{0}}{=}\, \lim_{x\to a}\frac{f'(x)}{g'(x)} = \frac{f'(a)}{g'(a)}} \] • 秒殺中叢 p.2-2 第3題根式極限：$\lim_{x\to -1}\d\frac{\sqrt{x+5}-2}{x+1} \overset{\frac{0}{0}}{=} \lim_{x\to -1}\d\frac{\d\frac{1}{2\sqrt{x+5}}}{1} = \color{#dc2626}{\d\frac{1}{4}}$（免有理化，3秒驗算完畢！）。
• 秒殺中叢 p.2-4 第12題：已知多項函數 $f(x)$ 滿足 $f(1)=3,\ f'(1)=5$，求 $\lim_{x\to 1}\d\frac{f(x)-3}{x-1} \overset{\frac{0}{0}}{=} \d\frac{f'(1)-0}{1} = f'(1) = \color{#dc2626}{5}$！
💡 【觀念盲點破解】看到極限式 $\lim_{x\to a}\d\frac{f(x)-k}{x-a}=m$，隱藏了哪兩個破題條件？（對應中叢 p.2-4 第11～12題、p.2-12 第17題） 只要多項式極限 $\lim_{x\to a}\d\frac{f(x)-k}{x-a} = m$ 存在，因為分母趨近於 $0$，分子也必須趨近於 $0$！因此一秒拆解出兩個條件：
① 函數值條件：$f(a) = k$（通過點 $(a,k)$）；② 導數（切線斜率）條件：$f'(a) = m$。
• 中叢 p.2-4 第11題秒殺：已知 $f(1)=0,\ f'(1)=20$，則 $\lim_{x\to 1}\d\frac{f(x)}{4(x-1)} = \d\frac{1}{4}\lim_{x\to 1}\d\frac{f(x)-f(1)}{x-1} = \d\frac{1}{4}f'(1) = \color{#dc2626}{5}$！
2. 圖形切線斜率比大小 ＆ 絕對值、高斯函數的可微性（對應中叢 p.2-2 第4～5題、p.2-3 第7～8題）
📘 【視覺化判讀定理】看圖判斷「切線斜率大小」與「不可微的三大幾何特徵」（對應中叢 p.2-2 第5題、p.2-3 第7題）
  • 看圖比較導數 $f'(x)$ 大小（中叢 p.2-3 第7題，如右圖）：
    導數 $f'(a)$ 就是切線斜率！遞增區間斜率為正（越陡正越多）、遞減區間斜率為負（越陡負越多，數值越小）、波峰波谷水平切線斜率為 $0$。故右圖大小順序為： \[ \color{#dc2626}{f'(0)} \lt \color{#d97706}{f'(-1)} \lt 0 \lt \color{#16a34a}{f'(-2)} \lt \color{#dc2626}{f'(2)} \]
  • 看圖秒判「不可微」的三種點（中叢 p.2-2 第5題）：
    函數在 $x=a$ 可微分，圖形在該點必須連續且平滑且切線不鉛直。若出現：
    ① 不連續點（跳躍斷裂、有空洞，如第5題(1)(2)(4)） $\implies$ 不可微！
    ② 尖點／折角點（左切線斜率 $\neq$ 右切線斜率，如第5題(5)） $\implies$ 不可微！
    ③ 鉛直切線點（切線斜率趨近 $\pm\infty$） $\implies$ 不可微！
⚡ 【範例 1-2】絕對值函數 $f(x)=|x-1|$ 與高斯函數 $f(x)=[x]$ 的導數（對應中叢 p.2-2 第4題、p.2-3 第8題）
題目 A（絕對值函數，中叢 p.2-2 第4題）：設 $f(x)=|x-1|$，求：(1) $\lim_{x\to 1}f(x)$；(2) $f'(1)$；(3) $f'(0)$。
精解 A（如右上圖）：
(1) 當 $x\to 1$ 時，$\lim_{x\to 1}|x-1| = \color{#2563eb}{0}$（在 $x=1$ 處連續）。
(2) 檢驗 $x=1$ 的左右導數：右導數 $\lim_{x\to 1^+}\d\frac{x-1}{x-1}=\color{#dc2626}{1}$，左導數 $\lim_{x\to 1^-}\d\frac{-(x-1)}{x-1}=\color{#2563eb}{-1}$。左右導數不相等（圖形為折角尖點），故 $f'(1)$ 不存在！
(3) 當 $x=0$ 在折點左側區間（$x\lt 1$）時，$f(x)=-x+1$，斜率為 $f'(0) = -1$。
題目 B（高斯函數，中叢 p.2-3 第8題）：設 $f(x)=[x]$ 為高斯函數，求：(1) $f'(\d\frac{5}{2})$；(2) $f'(2)$。
精解 B（如右下圖）：
(1) 在開區間 $(2,3)$ 內，$f(x)=[x]=2$ 為水平常數函數，故在內部點 $x=\d\frac{5}{2}$ 處切線斜率 $f'(\d\frac{5}{2}) = 0$。
(2) 在整數點 $x=2$ 處，左極限為 $1$、右極限為 $2$，圖形跳躍不連續，不連續必不可微，故 $f'(2)$ 不存在！
範例答案：題A：(1) $0$ (2) 不存在 (3) $-1$；題B：(1) $0$ (2) 不存在

（二）導函數與微分公式、分段函數可微性與切線全解析（中叢 p.2-5 ～ p.2-12）
1. 四大微分法則、連鎖律與二階導數極限（對應中叢 p.2-5 重點1～3、p.2-6～2-8 第1～5題、p.2-10 第12～13題、p.2-12 第18題）
📘 【核心公式表】多項式微分法則、商的微分法與合成函數連鎖律（對應中叢 p.2-5 重點1～3）
  • 基本冪次法則與線性性質：$(c)'=0$；$\color{#dc2626}{(x^n)' = n x^{n-1}}$；$(f(x)\pm g(x))' = f'(x) \pm g'(x)$。
  • 乘法微分法則（前微後不微＋前不微後微）：$\color{#2563eb}{(f(x)\cdot g(x))' = f'(x)g(x) + f(x)g'(x)}$。
  • 商的微分法則（分母平方，上微乘下減上乘下微）：$\color{#dc2626}{\left(\d\frac{f(x)}{g(x)}\right)' = \d\frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}}$（其中 $g(x)\neq 0$）。
  • 合成函數連鎖律（外函數微分 $\times$ 內函數微分）：$\color{#dc2626}{[(g(x))^n]' = n[g(x)]^{n-1}\cdot g'(x)}$；一般式 $(g\circ f)'(x) = g'(f(x))\cdot f'(x)$。
⚡ 【範例 2-1】分式函數商的微分、高次合成函數連鎖律與二階導數極限（對應中叢 p.2-7 第2題、p.2-10 第13題、p.2-12 第18題） 題目 A（商的微分法，中叢 p.2-7 第2(2)題）：設 $f(x)=\d\frac{x}{x^2-1}$，求 $f'(x)$ 與 $f'(0)$。
精解 A：套用商的微分公式：$f'(x) = \d\frac{(x)'(x^2-1) - x(x^2-1)'}{(x^2-1)^2} = \d\frac{1(x^2-1) - x(2x)}{(x^2-1)^2} = \color{#2563eb}{\d\frac{-x^2-1}{(x^2-1)^2}}$。代入 $x=0$ 得 $f'(0) = \color{#dc2626}{-1}$。
題目 B（乘法法則結合連鎖律，中叢 p.2-12 第18題）：已知多項式滿足 $f(1)=2,\ f'(1)=-3$，$g(x)=(2x-1)^3 f(x) - 2x$，求 $g'(1)$。
精解 B：由乘法法則與連鎖律（注意 $(2x-1)^3$ 微分要乘內層導數 $2$！）：
$\color{#2563eb}{g'(x) = 3(2x-1)^2 \cdot 2 \cdot f(x) + (2x-1)^3 f'(x) - 2}$。代入 $x=1$ 得 $g'(1) = 6(1)^2 f(1) + (1)^3 f'(1) - 2 = 6(2) + (-3) - 2 = \color{#dc2626}{7}$。
題目 C（導函數的差商極限 $=$ 二階導數，中叢 p.2-10 第13題）：設 $f(x)=x^3-2x^2+5x-1$，求 $\lim_{x\to 3}\d\frac{f'(x)-f'(3)}{x-3}$ 的值。
精解 C：觀察極限結構，這正是把 $f'(x)$ 當作原函數在 $x=3$ 的導數定義，即二階導數 $f''(3)$！
因 $f'(x)=3x^2-4x+5 \implies \color{#2563eb}{f''(x)=6x-4}$，故所求 $= f''(3) = 6(3)-4 = \color{#dc2626}{14}$。
範例答案：題A：$f'(x)=\d\frac{-x^2-1}{(x^2-1)^2},\ f'(0)=-1$；題B：$7$；題C：$14$
⚠️ 【考場易錯盲點】連鎖律最容易漏乘「內層導數 $g'(x)$」！（對應中叢 p.2-7 第2(5)～(7)題、p.2-8 第3～4題） 計算如 $f(x)=(2x+3)^3$ 的導函數時，許多同學直接寫成 $3(2x+3)^2$ 而痛失分數！請務必養成反射動作：外層次方搬下來減 $1$ 後，後面一定要緊跟著乘上括號內層的微分 $(2x+3)' = 2$，正確答案為 $3(2x+3)^2 \cdot \color{#dc2626}{2} = 6(2x+3)^2$！
2. 可微與連續的邏輯關係 ＆ 分段定義函數可微的判定法（對應中叢 p.2-5 重點4、p.2-11 第14～16題）
📘 【核心定理】「可微 $\implies$ 連續」與分段函數在交界點 $x=a$ 可微的雙重檢驗（對應中叢 p.2-5 重點4、p.2-11）
  • 可微與連續的關係：
    1. 原命題恆真：若 $f(x)$ 在 $x=c$ 可微 $\implies f(x)$ 在 $x=c$ 必連續。
    2. 逆命題不真：連續函數在 $x=c$ 未必可微（例如折角尖點 $|x-1|$）。
    3. 逆否命題恆真（秒殺利器）：若在 $x=c$ 不連續 $\implies$ 必不可微！
💡 【考場秒殺階層圖（嚴謹完整版）】（對應中叢 p.2-2 第4～5題、p.2-5 重點4、p.2-11 第14題） 在 $x=a$ 為定義域內點（兩側皆有定義）的前提下，必考單向推論鏈：
$\color{#dc2626}{\text{可微分}} \implies \color{#2563eb}{\text{連續}} \implies \color{#2563eb}{\text{極限存在}} \iff \text{左極限} = \text{右極限} = \text{定值 } L$
◆ 反向成立需補足條件（單向箭頭反向皆不成立，除非補足條件）：
  • 「極限存在 $= L$」 $\implies$ 「連續」：需補 $f(a) = L$（否則如中叢 p.2-2 第5(1)(2)題之空心點或跳躍點）。
  • 「連續」 $\implies$ 「可微分」：需補 $\text{左導數} = \text{右導數} = \text{有限定值}$（否則如中叢 p.2-2 第4題 $|x-1|$ 與第5(5)題之折角尖點，或鉛直切線斜率 $\pm\infty$）。
◆ 區間端點例外：若 $x=a$ 為定義域端點（如中叢 p.2-2 第3題 $f(x)=\sqrt{x+5}$ 在端點 $x=-5$，或 $f(x)=\sqrt{x}$ 在 $a=0$），連續僅需單側極限，無法推得雙側極限相等；若左右極限同趨近 $\pm\infty$ 則非定值故極限不存在。
  • 分段函數 $f(x)=\begin{cases} g(x), & x\le a \\ h(x), & x\gt a \end{cases}$ 在交界處 $x=a$ 可微的充要條件：
    第一步（先檢驗連續，左右高度相等）：$\color{#2563eb}{g(a) = h(a)}$。
    第二步（再檢驗平滑，左右斜率相等）：$\color{#dc2626}{g'(a) = h'(a)}$。
（兩軸單位長 1:1 精準比例）
（註：兩軸刻度比例不同）
⚡ 【範例 2-2】分段函數可微性判別與未知係數求解（對應中叢 p.2-11 第14, 15, 16題） 題目 A（四小題完整判別，中叢 p.2-11 第14題）：判斷下列分段函數在指定點是否可微：
(1) $f(x)=\begin{cases} x^3, & x\le 0 \\ -x^3, & x\gt 0 \end{cases}$ 於 $x=0$：先看連續 $0=0$（成立）；再看左右導數：$3(0)^2 = 0 = -3(0)^2$（相等），故可微。
(2) $f(x)=\begin{cases} x^2+1, & x\le 1 \\ 2x, & x\gt 1 \end{cases}$ 於 $x=1$：先看連續 $1^2+1=2(1)=2$（成立）；再看左右導數：$2(1) = 2 = 2$（相等），故可微。
(3) $f(x)=\begin{cases} x^2-1, & x\lt 2 \\ x+1, & x\ge 2 \end{cases}$ 於 $x=2$（如上方定理框右下圖）：雖連續（$2^2-1=2+1=3$），但左導數 $2(2)=4 \neq$ 右導數 $1$（折角點），故不可微！
(4) $f(x)=\begin{cases} x^2+2x, & x\lt 1 \\ 4x-1, & x\ge 1 \end{cases}$ 於 $x=1$：連續 $1+2=4-1=3$；左導數 $(2x+2)|_{x=1}=4 =$ 右導數 $4$，故可微。
題目 B（可微求係數，中叢 p.2-11 第16題）：設函數 $f(x)=\begin{cases} x^3, & x\le 2 \\ x^2+ax+b, & x\gt 2 \end{cases}$ 在 $x=2$ 處可微分，求 $f(3)$ 的值。
精解 B：利用「一連續、二平滑」直接列聯立：
① 左導數 $=$ 右導數（先算導數可消去 $b$！）：$(3x^2)|_{x=2} = (2x+a)|_{x=2} \implies 12 = 4+a \implies \color{#dc2626}{a = 8}$。
② 左極限 $=$ 右極限（連續）：$2^3 = 2^2 + 8(2) + b \implies 8 = 20 + b \implies \color{#2563eb}{b = -12}$。
當 $x=3\gt 2$ 時，代入下段式得 $f(3) = 3^2 + 8(3) - 12 = \color{#dc2626}{21}$。
範例答案：題A：(1)可微 (2)可微 (3)不可微 (4)可微；題B：$f(3)=21$（且 $a=8,\ b=-12$）
⚠️ 【考場易錯盲點】分段函數千萬別「還沒檢查連續，就直接微分代數字」！ 例如若題目改為 $f(x)=\begin{cases} x^2+5, & x\le 1 \\ 2x, & x\gt 1 \end{cases}$，若你直接兩邊微分代 $x=1$，會發現左導數 $2(1)=2$、右導數也是 $2$，誤以為可微！但其實在 $x=1$ 左極限為 $6 \neq$ 右極限 $2$（根本不連續），連極限都不存在，當然不可微！

📘 【四大題型破題總綱】切點已知 vs 切點未知 vs 斜率極值（對應中叢 p.2-8～2-10）

題目 B（三次曲線切線與另交點，中叢 p.2-9 第9題，如上方定理框第二圖）：點 $Q(1,-3)$ 在 $\Gamma: y=x^3-4x$ 上，求以 $Q$ 為切點之切線 $L$ 及 $L$ 與 $\Gamma$ 所有交點。
精解 B：$f'(x)=3x^2-4 \implies$ 斜率 $f'(1)=\color{#dc2626}{-1}$，切線 $L: \color{#2563eb}{y+3=-(x-1)}$（即 $y=-x-2$）。聯立 $x^3-4x=-x-2 \implies x^3-3x+2=(x-1)^2(x+2)=0 \implies x=1, -2$，故交點為 $(1,-3)$ 與 $(-2,0)$。
題目 C（斜率最大之切線，中叢 p.2-10 第10題，如右下圖）：求 $f(x)=-x^3+3x^2$ 的所有切線中，斜率最大之切線方程式。
精解 C：切線斜率函數為 $m(x) = f'(x) = -3x^2+6x = -3(x-1)^2+3$。當 $x=1$ 時，有最大切線斜率 $m=3$，此時切點為 $(1, f(1)) = (1,2)$，故切線方程式為 $\color{#dc2626}{y-2=3(x-1)}$。

📘 【核心定理】一階導數與二階導數在運動學與幾何變化率的物理意義（對應中叢 p.2-13～2-14）

    • 水槽放水／球體膨脹：水體積 $V(t)$ 對時間 $t$ 的瞬時變化率為 $V'(t)$（放水減少時導數為負值！）。

⚡ 【範例 3-1】藥物血壓敏感度、汽車煞車、水槽放水與圓球體積變化率（對應中叢 p.2-13 第1題、p.2-14 第2～4題）
題目 A（藥物血壓敏感度，中叢 p.2-13 第1題）：服用藥物 $x$ cc 後最高血壓 $P(x)=-0.3x^3+0.04x^2+80 \ (0\le x\le 6)$，求敏感度函數 $P'(x)$ 及服用 $2$ cc 時的血壓變化率。
精解 A：直接微分得 $\color{#2563eb}{P'(x) = -0.9x^2+0.08x}$，代入 $x=2$ 得 $P'(2) = -0.9(4)+0.08(2) = \color{#dc2626}{-3.44}$。
題目 B（汽車煞車速度與加速度，中叢 p.2-14 第2題，如上方定理框圖示）：煞車後 $t$ 秒內前進的距離為 $s(t)=-\d\frac{1}{3}t^3+2t$（其中 $0\le t\le \sqrt{2}$），求：(1) $t=1$ 時瞬時速度；(2) $t=1$ 時瞬時加速度。
精解 B：(1) 瞬時速度函數 $v(t) = s'(t) = \color{#2563eb}{-t^2 + 2}$，代入 $t=1$ 得瞬時速度 $v(1) = -(1)^2+2 = \color{#dc2626}{1}$。
(2) 瞬時加速度函數 $a(t) = v'(t) = s''(t) = \color{#2563eb}{-2t}$，代入 $t=1$ 得瞬時加速度 $a(1) = \color{#dc2626}{-2}$。
題目 C（水槽放水變化率，中叢 p.2-14 第3題，如右圖）：放水 $t$ 分鐘後水體積 $V(t)=100\left(1-\d\frac{t}{120}\right)^2$ 公升，求 $t$ 分鐘與 $t=6$ 分鐘時的瞬時變化率。
精解 C：由連鎖律（注意內層微分要乘 $-\d\frac{1}{120}$！）：$V'(t) = 200\left(1-\d\frac{t}{120}\right)\left(-\d\frac{1}{120}\right) = \color{#2563eb}{\d\frac{t}{72}-\d\frac{5}{3}}$。代入 $t=6$ 得 $V'(6) = \d\frac{6}{72}-\d\frac{5}{3} = \color{#dc2626}{-\d\frac{19}{12}}$（公升/分）。
題目 D（圓球膨脹變化率，中叢 p.2-14 第4題）：圓球半徑以每秒 $3$ 公分等速由零增加，求第 $2$ 秒時體積的變化率（$V=\d\frac{4}{3}\pi r^3$）。
精解 D：將半徑表示為時間函數 $r(t) = 3t$，代入體積得 $V(t) = \d\frac{4}{3}\pi (3t)^3 = \color{#2563eb}{36\pi t^3}$。對時間 $t$ 微分得 $V'(t) = 108\pi t^2$，代入 $t=2$ 得 $V'(2) = 108\pi(4) = \color{#dc2626}{432\pi}$（$\text{cm}^3/\text{sec}$）。
範例答案：題A：$P'(x)=-0.9x^2+0.08x,\ -3.44$；題B：$1,\ -2$；題C：$\d\frac{t}{72}-\d\frac{5}{3},\ -\d\frac{19}{12}$；題D：$432\pi$
（註：橫軸每格30分，縱軸每格25公升）
⚠️ 【考場易錯盲點】圓球體積對「時間 $t$」的變化率 vs 對「半徑 $r$」的變化率（中叢 p.2-14 第4題） 在中叢 p.2-14 第 4 題中，千萬不可直接對半徑微分算 $\d\frac{dV}{dr} = 4\pi r^2$ 再代入 $r=6$ 得到 $144\pi$！因為題目問的是「每秒體積變化多少（對時間 $t$ 微分 $\d\frac{dV}{dt}$）」，必須乘上半徑對時間的膨脹速率 $\d\frac{dr}{dt}=3$（即連鎖律 $\d\frac{dV}{dt} = 4\pi r^2 \cdot \d\frac{dr}{dt} = 144\pi \times 3 = \color{#dc2626}{432\pi}$），或一開始就換成 $r=3t$ 代入！
2. 多項式的冪級數（泰勒展開式）與一次近似估計（對應中叢 p.2-13 重點1～2、p.2-15～2-16 第5～8題）
📘 【定理與公式】泰勒展開式係數公式與一次近似（切線逼近法）（對應中叢 p.2-13 重點1～2）
將 $n$ 次多項式 $f(x)$ 在 $x=a$ 展開為以 $(x-a)$ 為冪次的泰勒展開式： \[ f(x) = a_0 + a_1(x-a) + a_2(x-a)^2 + a_3(x-a)^3 + \cdots + a_n(x-a)^n \] 其中常數項 $\color{#2563eb}{a_0 = f(a)}$，一次項係數 $\color{#dc2626}{a_1 = f'(a)}$，二次項係數 $\color{#2563eb}{a_2 = \d\frac{f''(a)}{2!}}$，第 $k$ 次項係數 $a_k = \d\frac{f^{(k)}(a)}{k!}$。
當 $x$ 非常接近 $a$ 時，忽略二次以上高次微小項，得 $f(x)$ 在 $x=a$ 附近的一次近似（一次估計）即為切線方程式： \[ \color{#dc2626}{y = f(a) + f'(a)(x - a)} \]
（註：兩軸刻度比例不同，示意切線逼近）
⚡ 【範例 3-2】泰勒展開式、一次估計與近似值計算（對應中叢 p.2-15 第5～6題、p.2-16 第7～8題） 題目 A（泰勒展開與誤差，中叢 p.2-15 第5題）：設 $f(x)=x^3+4x^2-3x+1$，(1) 表成 $\sum_{k=0}^3 a_k(x-1)^k$；(2) 求在 $x=1$ 的一次估計；(3) 已知 $f(1.01)=3.080701$，與一次估計相差多少？
精解 A：逐次微分代 $x=1$：$a_0=f(1)=\color{#2563eb}{3}$；$f'(x)=3x^2+8x-3 \implies a_1=f'(1)=\color{#dc2626}{8}$；$f''(x)=6x+8 \implies a_2=\d\frac{f''(1)}{2!}=\color{#2563eb}{7}$；$a_3=1$。
(1) $f(x)=\color{#2563eb}{3+8(x-1)+7(x-1)^2+(x-1)^3}$。(2) 一次估計為 $\color{#dc2626}{y=3+8(x-1)}$。(3) 代入 $x=1.01$ 得近似值 $3.08$，相差 $\color{#2563eb}{0.000701}$。
題目 B（四次多項式一次估計，中叢 p.2-16 第8題）：設 $f(x)=x^4+3x^3-x+2$，(1) 求 $f(1)$；(2) 寫出在 $x=1$ 的一次估計；(3) 求 $f(0.998)$ 近似值。
精解 B：(1) $\color{#2563eb}{f(1)=1+3-1+2=5}$。(2) 求導 $f'(x)=4x^3+9x^2-1 \implies \color{#dc2626}{f'(1)=12}$，故一次估計為 $\color{#dc2626}{y=5+12(x-1)}$。
(3) 將 $x=0.998$（即 $x-1=-0.002$）代入一次估計：$f(0.998) \approx 5 + 12(-0.002) = 5 - 0.024 = \color{#dc2626}{4.976}$。
範例答案：題A：(1) $3+8(x-1)+7(x-1)^2+(x-1)^3$ (2) $y=3+8(x-1)$ (3) $0.000701$；題B：(1) $5$ (2) $y=5+12(x-1)$ (3) $4.976$
3. 牛頓法求根的近似值（課綱延伸補充）
📘 【定理與公式】以切線與 $x$ 軸交點逐步逼近無理實根
設 $f(x)=0$ 有一實根 $\alpha$。選定初始近似值 $x_0$，作點 $P(x_0, f(x_0))$ 的切線 $y - f(x_0) = f'(x_0)(x - x_0)$，令 $y=0$ 求切線與 $x$ 軸交點，得下一個近似值遞迴公式： \[ \color{#dc2626}{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}} \] • 觀念盲點提醒：若選到極值點導致 $f'(x_n)=0$，切線水平不交 $x$ 軸，牛頓法即失效！
