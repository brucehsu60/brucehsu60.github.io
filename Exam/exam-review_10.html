(　　) 1. 下列哪個數值最小？
(1) $\cos 10^\circ \cos 40^\circ + \sin 10^\circ \sin 40^\circ$
(2) $\cos 10^\circ \cos 70^\circ + \sin 10^\circ \sin 70^\circ$
(3) $\cos 10^\circ \cos 100^\circ + \sin 10^\circ \sin 100^\circ$
(4) $\cos 10^\circ \cos 130^\circ + \sin 10^\circ \sin 130^\circ$
(5) $\cos 10^\circ \cos 160^\circ + \sin 10^\circ \sin 160^\circ$
📘 正規詳解
利用餘弦的差角公式 $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$ 化簡各選項：
  • (1) $\cos 10^\circ \cos 40^\circ + \sin 10^\circ \sin 40^\circ = \cos(40^\circ - 10^\circ) = \cos 30^\circ = \d\frac{\sqrt{3}}{2}$
  • (2) $\cos 10^\circ \cos 70^\circ + \sin 10^\circ \sin 70^\circ = \cos(70^\circ - 10^\circ) = \cos 60^\circ = \d\frac{1}{2}$
  • (3) $\cos 10^\circ \cos 100^\circ + \sin 10^\circ \sin 100^\circ = \cos(100^\circ - 10^\circ) = \cos 90^\circ = 0$
  • (4) $\cos 10^\circ \cos 130^\circ + \sin 10^\circ \sin 130^\circ = \cos(130^\circ - 10^\circ) = \cos 120^\circ = -\cos 60^\circ = -\d\frac{1}{2}$
  • (5) $\cos 10^\circ \cos 160^\circ + \sin 10^\circ \sin 160^\circ = \cos(160^\circ - 10^\circ) = \cos 150^\circ = -\cos 30^\circ = -\d\frac{\sqrt{3}}{2}$
因為 $\cos\theta$ 在 $0^\circ \le \theta \le 180^\circ$ 為嚴格遞減函數，角度愈大其餘弦值愈小，故 $\cos 150^\circ = -\d\frac{\sqrt{3}}{2}$ 為最小，選 (5)。
⚡ 學霸另解（單位圓向量內積法）
將式子視為單位圓上兩向量 $\vec{u} = (\cos 10^\circ, \sin 10^\circ)$ 與 $\vec{v}_\theta = (\cos\theta, \sin\theta)$ 的內積 $\vec{u}\cdot\vec{v}_\theta = 1\cdot 1\cdot\cos\Delta\theta$。當兩向量夾角 $\Delta\theta$ 愈接近 $180^\circ$（反向），內積值愈小。$160^\circ$ 與 $10^\circ$ 相差 $150^\circ$ 最大，秒選 (5)！
⏱️ 學霸考場驗算（10 秒象限正負判別）
$10^\circ$ 在第一象限 ($\cos>0, \sin>0$)。選項 (1)(2) 兩項皆正；(3) 為 $0$；(4)(5) 在第二象限，其中 $160^\circ$ 比 $130^\circ$ 更靠近 $-x$ 軸 ($\cos 160^\circ \approx -0.94$ 負得更多，且 $\sin 160^\circ$ 很小)，瞬間確認 (5) 最小。
最終答案：(5)
(　　) 2. 試問 $y = \d\frac{x}{2\pi}$ 的函數圖形與 $y = 2 \sin 2x$ 的函數圖形有幾個交點？
(1) 12 個
(2) 13 個
(3) 14 個
(4) 15 個
(5) 16 個
📘 正規詳解
1. 函數 $y = 2 \sin 2x$ 的振幅為 $2$（值域為 $-2 \le y \le 2$），週期為 $\d\frac{2\pi}{2} = \pi$。
2. 直線 $y = \d\frac{x}{2\pi}$ 通過原點 $(0,0)$：
　・當 $x > 4\pi$ 時，$y = \d\frac{x}{2\pi} > 2$；
　・當 $x < -4\pi$ 時，$y = \d\frac{x}{2\pi} < -2$。
　因此兩圖形只在區間 $[-4\pi , 4\pi]$ 內有交點。
3. 在右半邊 $[0 , 4\pi]$ 中，長度為 $4\pi$，共包含 $\d\frac{4\pi}{\pi} = 4$ 個完整週期。每個週期的「正半波（波峰高為 $2$）」都會被直線 $y = \d\frac{x}{2\pi}$ 穿過 $2$ 次（第 4 個波峰在 $x = \d\frac{13\pi}{4} < 4\pi$，此時直線高度僅 $\d\frac{13}{8} < 2$），故在 $x \ge 0$ 共有 $4 \times 2 = 8$ 個交點（含原點 $(0,0)$，即原點與 $x > 0$ 的 $7$ 個交點）。
4. 由奇函數對稱於原點的性質，在 $[-4\pi , 0)$ 亦有 $7$ 個交點。
5. 總交點數 $= 7 + 1 + 7 = 15$ 個，故選 (4)。
💡 考場秒殺公式与易錯盲點
對於奇函數 $y = A\sin(\omega x)$ 與過原點斜直線 $y = mx$ 的交點個數問題：
・因為圖形對稱於原點 $(0,0)$，且 $(0,0)$ 必為交點，總交點數必為奇數！直接刪去偶數選項 (1) 12、(3) 14、(5) 16，二選一瞬間鎖定 (2) 或 (4)。
・右半邊共有 $n = 4$ 座波峰高於直線，交點總數秒殺公式為 $4n - 1 = 4(4) - 1 = 15$ 個！
最終答案：(4)
(　　) 3. 日本浮世繪大師葛飾北齋擅長以圓形和三角形來構圖。如右圖，要畫一隻小老鼠，可以先作一個以點 $O$ 為圓心的圓 $\Gamma$，在圓外取一點 $P$，過 $P$ 作圓 $\Gamma$ 的切線段 $\overline{PA}$ 及 $\overline{PB}$，即完成小老鼠的身體。若圓 $\Gamma$ 的半徑為 6，$A$，$B$ 為切點且 $\angle APB = \d\frac{\pi}{3}$，則小老鼠的下半身優弧 $\overparen{ACB}$ 之弧長最接近下列何者？
(1) 6
(2) 12
(3) 13
(4) 25
(5) 31
📘 正規詳解
1. 連接圓心與切點作半徑 $\overline{OA}$ 與 $\overline{OB}$，由切線性質知 $\overline{OA} \perp \overline{PA}$，$\overline{OB} \perp \overline{PB}$。
2. 在四邊形 $OAPB$ 中，內角和為 $2\pi$，故劣弧所對的圓心角為： $$\angle AOB = 2\pi - \d\frac{\pi}{2} - \d\frac{\pi}{2} - \d\frac{\pi}{3} = \d\frac{2}{3}\pi$$ 3. 因此優弧 $\overparen{ACB}$ 所對的圓心角為 $2\pi - \d\frac{2}{3}\pi = \d\frac{4}{3}\pi$，由弧長公式 $s = r\theta$ 得： $$\overparen{ACB} = 6 \times \left(2\pi - \d\frac{2\pi}{3}\right) = 8\pi \approx 8 \times 3.14 = 25.12$$ 最接近 $25$，故選 (4)。
⏱️ 學霸考場驗算（比例直覺法）
整圈圓周長為 $2\pi r = 12\pi \approx 37.7$。因為切線夾角 $60^\circ$，圓心角與其互補為 $120^\circ$（佔 $\d\frac{1}{3}$ 圓），所以優弧 $\overparen{ACB}$ 佔了整圓的 $\d\frac{2}{3}$！直接算 $37.7 \times \d\frac{2}{3} \approx 25.1$，秒殺驗證無誤。
最終答案：(4)
108.全國模考 (　　) 4. 若函數 $f(x) = 2 \sin \left( x + \d\frac{\pi}{6} \right) - 2 \cos x + 5$，則函數 $f(x)$ 的最大值為何？
(1) 7
(2) 5
(3) 3
(4) 1
(5) 0
📘 正規詳解
利用正弦和角公式將 $f(x)$ 展開並實施正餘弦疊合： $$\begin{aligned} f(x) &= 2 \sin\left(x + \d\frac{\pi}{6}\right) - 2\cos x + 5 \\ &= 2\left(\sin x \cos\d\frac{\pi}{6} + \cos x \sin\d\frac{\pi}{6}\right) - 2\cos x + 5 \\ &= 2\left(\sin x \cdot \d\frac{\sqrt{3}}{2} + \cos x \cdot \d\frac{1}{2}\right) - 2\cos x + 5 \\ &= \sqrt{3}\sin x - \cos x + 5 \\ &= 2\left(\d\frac{\sqrt{3}}{2}\sin x - \d\frac{1}{2}\cos x\right) + 5 = 2\sin\left(x - \d\frac{\pi}{6}\right) + 5 \end{aligned}$$ 當 $x = \d\frac{2\pi}{3} + 2k\pi$（$k$ 為整數）時，$\sin\left(x - \d\frac{\pi}{6}\right) = 1$，$f(x)$ 有最大值 $2 \times 1 + 5 = 7$，故選 (1)。
⚡ 學霸另解（向量合成法／相量法）
注意到 $-\cos x = \sin\left(x - \d\frac{\pi}{2}\right)$。原式可看成兩個長度皆為 $2$ 的波： $$2\sin\left(x + \d\frac{\pi}{6}\right) + 2\sin\left(x - \d\frac{\pi}{2}\right)$$ 兩者相位角相差 $\d\frac{\pi}{6} - \left(-\d\frac{\pi}{2}\right) = \d\frac{2\pi}{3} = 120^\circ$！
兩個長度為 $2$ 且夾角 $120^\circ$ 的等長向量，其合成向量長度仍為 $2$！因此疊合後振幅必為 $2$，最大值 $= 2 + 5 = 7$，完全不用展開半個根號！
最終答案：(1)

(　　) 5. 設 $\theta$ 為第二象限角，則下列哪些選項正確？
(1) $\sin \d\frac{\theta}{2} > 0$
(2) $\cos \d\frac{\theta}{2} > 0$
(3) $\tan \d\frac{\theta}{2} > 0$
(4) $\sin 2\theta < 0$
(5) $\cos 2\theta < 0$
📘 正規詳解
因為 $\theta$ 為第二象限角，必須寫出同界角一般式： $$90^\circ + 360^\circ \times n < \theta < 180^\circ + 360^\circ \times n \quad (\text{其中 } n \text{ 為整數})$$
  • 判斷 $\d\frac{\theta}{2}$ 的範圍（選項 1、2、3）：
    將不等式同除以 $2$，得： $$45^\circ + 180^\circ \times n < \d\frac{\theta}{2} < 90^\circ + 180^\circ \times n$$ ・當 $n$ 為偶數時，$\d\frac{\theta}{2}$ 為第一象限角（$\sin\d\frac{\theta}{2} > 0, \cos\d\frac{\theta}{2} > 0$）；
    ・當 $n$ 為奇數時（例如取 $\theta = 460^\circ$ 為第二象限角，則 $\d\frac{\theta}{2} = 230^\circ$），$\d\frac{\theta}{2}$ 為第三象限角（$\sin 230^\circ < 0, \cos 230^\circ < 0$）。
    但無論在第一象限或第三象限，正切值皆為正，故 $\tan\d\frac{\theta}{2} > 0$ 恆成立！因此 (1) 錯誤、(2) 錯誤、(3) 正確。
  • 判斷 $2\theta$ 的範圍（選項 4、5）：
    將不等式同乘以 $2$，得： $$180^\circ + 720^\circ \times n < 2\theta < 360^\circ + 720^\circ \times n$$ 可知 $2\theta$ 的終邊落在 $x$ 軸下方（第三象限角、第四象限角或 $270^\circ$ 的同界角），因此 $y$ 坐標恆負，即 $\sin 2\theta < 0$ 恆成立；但當 $2\theta$ 為第四象限角時，$\cos 2\theta > 0$。故 (4) 正確、(5) 錯誤。
故選 (3)(4)。
⚡ 學霸另解（二倍角與半角恆等式判號法）
已知 $\theta \in \text{II}$，故 $\sin\theta > 0$ 且 $\cos\theta < 0$：
・由二倍角公式 $\sin 2\theta = 2\sin\theta\cos\theta = 2(+)(-) < 0$，瞬間確定 (4) 必對！
・由半角正切有理公式 $\tan\d\frac{\theta}{2} = \d\frac{1 - \cos\theta}{\sin\theta} = \d\frac{1 - (-)}{+} = \d\frac{+}{+} > 0$，完全不必討論 $n$ 的奇偶，瞬間證明 (3) 恆正！
⚠️ 易錯盲點
千萬不可只寫 $90^\circ < \theta < 180^\circ \implies 45^\circ < \d\frac{\theta}{2} < 90^\circ$ 而誤選 (1)(2)！「第二象限角」包含負角與超過 $360^\circ$ 的廣義角，除以 $2$ 時週期 $360^\circ n$ 會變成 $180^\circ n$，象限會跳到對頂象限！
最終答案：(3)(4)
(　　) 6. 下列哪些函數的週期為 $\pi$？
(1) $y = \sin x \cos x$
(2) $y = \sin(x + \pi)$
(3) $y = \cos^2 x$
(4) $y = \sin x + \cos x$
(5) $y = |\sin x + \cos x|$
📘 正規詳解
  • (1) 正確：由二倍角公式，$y = \sin x \cos x = \d\frac{1}{2}(2\sin x\cos x) = \d\frac{1}{2}\sin 2x$，週期為 $\d\frac{2\pi}{2} = \pi$。
  • (2) 錯誤：水平平移不改變週期，$y = \sin(x + \pi) = -\sin x$ 的週期為 $\d\frac{2\pi}{1} = 2\pi$。
  • (3) 正確：由半角（降次）公式，$y = \cos^2 x = \d\frac{1 + \cos 2x}{2} = \d\frac{1}{2}\cos 2x + \d\frac{1}{2}$，週期為 $\d\frac{2\pi}{2} = \pi$。
  • (4) 錯誤：由正餘弦疊合， $$y = \sin x + \cos x = \sqrt{2}\left(\sin x \cdot \d\frac{1}{\sqrt{2}} + \cos x \cdot \d\frac{1}{\sqrt{2}}\right) = \sqrt{2}\sin\left(x + \d\frac{\pi}{4}\right)$$ 週期為 $\d\frac{2\pi}{1} = 2\pi$。
  • (5) 正確：由 (4) 知 $y = |\sin x + \cos x| = \left|\sqrt{2}\sin\left(x + \d\frac{\pi}{4}\right)\right|$。將正弦波在 $x$ 軸下方的負半波翻折至 $x$ 軸上方後，原本正負交替的波形變成完全相同的拱形，週期減半為 $\d\frac{2\pi}{2} = \pi$。
故選 (1)(3)(5)。
⚡ 學霸另解（代數平方去絕對值法）
判斷含有絕對值的 (5) $y = |\sin x + \cos x|$（非負函數）的週期時，因為 $y \ge 0$，其週期與 $y^2$ 完全相同！
直接平方：$y^2 = (\sin x + \cos x)^2 = 1 + 2\sin x\cos x = 1 + \sin 2x$，一眼看出週期為 $\d\frac{2\pi}{2} = \pi$！
最終答案：(1)(3)(5)
(　　) 7. 右圖為某地一天 24 小時海水漲落的水深紀錄圖，其中滿潮（即海平面上升至最高時）的時間為 6 時與 18 時，此時水深為 7 公尺，乾潮（即海平面下降至最低時）的時間為 0 時與 12 時，此時水深為 1 公尺。若水深 $y$（公尺）與時間 $x$（時）的關係可表為函數 $y = a \sin(bx + c) + d$，其中 $a$，$b$，$d > 0$ 且 $-\pi < c < 0$，則：
(1) 此函數的週期為 $2\pi$
(2) $a = 3$
(3) $b = \d\frac{\pi}{6}$
(4) $c = -3$
(5) $d = 1$
📘 正規詳解
  • (1) 錯誤：相鄰兩次滿潮（或乾潮）的時間間隔即為週期，故週期 $T = 18 - 6 = 12$（小時）。
  • (2) 正確、(5) 錯誤：因為 $a > 0$，最大值為 $7$、最小值為 $1$，故：
    振幅 $a = \d\frac{7 - 1}{2} = 3$；中心平衡位置（鉛直位移）$d = \d\frac{7 + 1}{2} = 4$。
  • (3) 正確：由週期公式 $T = \d\frac{2\pi}{b} = 12 \implies b = \d\frac{\pi}{6}$。
  • (4) 錯誤：將 $y = a\sin(bx + c) + d$ 提出 $b$ 改寫為： $$y = a\sin\left[b\left(x + \d\frac{c}{b}\right)\right] + d$$ 把 $y = a\sin bx + d$ 的圖形向右水平平移 $3$ 單位可得題圖（因為平衡點從 $x=0$ 移至 $x=3$），故 $-\d\frac{c}{b} = 3 \implies c = -3b = -3 \times \d\frac{\pi}{6} = -\d\frac{\pi}{2}$（符合 $-\pi < c < 0$）。
故選 (2)(3)。
⏱️ 學霸考場驗算（代起始點 $x = 0$ 秒殺 $c$）
不必背平移公式！直接將乾潮點 $(0, 1)$ 代入 $y = 3\sin\left(\d\frac{\pi}{6}x + c\right) + 4$：
$$3\sin(0 + c) + 4 = 1 \implies \sin c = -1$$ 因為 $-\pi < c < 0$，直接得出 $c = -\d\frac{\pi}{2} \neq -3$，2 秒鐘擊破選項 (4)！
最終答案：(2)(3)
(　　) 8. 已知坐標平面上三直線 $L$、$L_1$、$L_2$ 交於一點 $O$，其中 $L$ 為一條水平線，$\theta_1$、$\theta_2$ 分別為 $L$ 與 $L_1$、$L_2$ 的銳夾角；$m_1$、$m_2$ 分別為 $L_1$、$L_2$ 的斜率，且 $m_1 > 0$，$m_2 < 0$。請選出正確的選項。
(1) $m_1 = \tan \theta_1$
(2) $m_2 = \tan \theta_2$
(3) $\tan(\theta_1 + \theta_2) = \d\frac{m_1 + m_2}{1 - m_1 m_2}$
(4) 若 $\tan \theta_1 \times \tan \theta_2 = 1$，則 $L_1$ 與 $L_2$ 垂直
(5) 若 $m_1 m_2 < -1$，則 $\theta_1 + \theta_2 > 90^\circ$
📘 正規詳解
因為 $L$ 與 $x$ 軸平行，且 $\theta_1, \theta_2 \in (0^\circ , 90^\circ)$ 為銳夾角，$m_1 > 0$，$m_2 < 0$，所以 $L_1$ 與 $L_2$ 的有向斜角分別為 $\theta_1$ 與 $-\theta_2$（或 $180^\circ - \theta_2$）：
  • (1) 正確：$L_1$ 的斜角為 $\theta_1$，故 $m_1 = \tan\theta_1$。
  • (2) 錯誤：$L_2$ 的斜角為 $-\theta_2$，且 $m_2 < 0$，故 $m_2 = \tan(-\theta_2) = -\tan\theta_2$（即 $\tan\theta_2 = -m_2 > 0$）。
  • (3) 錯誤：由正切和角公式，將 $\tan\theta_1 = m_1$ 與 $\tan\theta_2 = -m_2$ 代入： $$\tan(\theta_1 + \theta_2) = \d\frac{\tan\theta_1 + \tan\theta_2}{1 - \tan\theta_1\tan\theta_2} = \d\frac{m_1 + (-m_2)}{1 - m_1(-m_2)} = \d\frac{m_1 - m_2}{1 + m_1 m_2}$$
  • (4) 正確：若 $\tan\theta_1 \times \tan\theta_2 = 1$，則斜率乘積 $m_1 m_2 = \tan\theta_1 \times (-\tan\theta_2) = -(\tan\theta_1\tan\theta_2) = -1 \implies L_1 \perp L_2$。
  • (5) 正確：由 (3) 知 $\tan(\theta_1 + \theta_2) = \d\frac{m_1 - m_2}{1 + m_1 m_2}$。
    因為 $m_1 > 0$ 且 $m_2 < 0$，所以分子 $m_1 - m_2 > 0$；又 $m_1 m_2 < -1$，所以分母 $1 + m_1 m_2 < 0$。
    因此 $\tan(\theta_1 + \theta_2) = \d\frac{+}{-} < 0$。由於 $0^\circ < \theta_1, \theta_2 < 90^\circ \implies 0^\circ < \theta_1 + \theta_2 < 180^\circ$，正切值為負代表 $\theta_1 + \theta_2$ 為鈍角，故 $90^\circ < \theta_1 + \theta_2 < 180^\circ$。
故選 (1)(4)(5)。
⏱️ 學霸考場驗算（幾何直覺與代特值法）
・幾何秒看 (4)(5)：當 $\theta_1 + \theta_2 = 90^\circ$ 時，$L_1, L_2$ 夾角為 $180^\circ - 90^\circ = 90^\circ$（垂直，$m_1 m_2 = -1$）。當 $m_1 m_2 < -1$（兩直線都變得更陡峭、更靠近鉛直線）時，銳夾角 $\theta_1, \theta_2$ 都變大，當然 $\theta_1 + \theta_2 > 90^\circ$！
・代特值秒殺：令 $\theta_1 = \theta_2 = 60^\circ$，則 $m_1 = \sqrt{3}$，$m_2 = -\sqrt{3}$，此時 $m_1 m_2 = -3 < -1$ 且 $\theta_1 + \theta_2 = 120^\circ > 90^\circ$，完全吻合！

12. 已知函數 $y = \sin x$，$\alpha \le x \le \alpha + \d\frac{\pi}{2}$，其中 $0 < \alpha < \pi$。若 $y$ 的最大值為 $A$，最小值為 $B$，則 $A - B$ 之最大值為 $\sqrt{\text{(12)}}$。
📘 正規詳解
分兩區段討論長度為 $\d\frac{\pi}{2}$ 的閉區間 $\left[\alpha , \alpha + \d\frac{\pi}{2}\right]$：
  • 情況 (1)：若 $0 < \alpha < \d\frac{\pi}{2}$，則 $\d\frac{\pi}{2} < \alpha + \d\frac{\pi}{2} < \pi$。
    此時區間包含波峰 $x = \d\frac{\pi}{2}$，且整個區間都在 $(0, \pi)$ 內，故： $$A = \sin\d\frac{\pi}{2} = 1 \quad , \quad B = \min\left\{\sin\alpha , \sin\left(\alpha + \d\frac{\pi}{2}\right)\right\} > 0$$ 因此 $0 < A - B < 1$。
  • 情況 (2)：若 $\d\frac{\pi}{2} \le \alpha < \pi$，則 $\pi \le \alpha + \d\frac{\pi}{2} < \d\frac{3\pi}{2}$。

【解法一：斜率與差角公式法】
因為直線 $OB$ 與直線 $OA$ 對稱於 $y$ 軸，直線 $OC$ 與直線 $OD$ 對稱於 $x$ 軸，所以： $$m_{OB} = -m_{OA} = -\d\frac{3}{4} \quad , \quad m_{OD} = -m_{OC} = -\d\frac{24}{7}$$ 設直線 $OB$ 的斜角為 $\alpha$，直線 $OD$ 的斜角為 $\beta$，直線 $OB$ 與直線 $OD$ 的銳夾角為 $\gamma$，則 $\gamma = \alpha - \beta$： $$\tan\gamma = \tan(\alpha - \beta) = \d\frac{m_{OB} - m_{OD}}{1 + m_{OB} \times m_{OD}} = \d\frac{-\d\frac{3}{4} - \left(-\d\frac{24}{7}\right)}{1 + \left(-\d\frac{3}{4}\right)\left(-\d\frac{24}{7}\right)} = \d\frac{3}{4} = \tan\angle AOC \implies \gamma = \angle AOC$$ 又 $\angle BOD + \gamma = \pi$（弳），所以 $\angle BOD + \angle AOC = \pi$（弳）。
設 $\angle AOC = \theta$（弳），$\angle BOD = \phi$（弳）$\implies \theta + \phi = \pi$（弳）。
灰色塊的 pizza 邊的長度為 $\overparen{AC} + \overparen{BD} = 25\theta + 25\phi = 25(\theta + \phi) = 25\pi$。

【解法三：圓弧對稱搬移法（最優雅幾何證法）】
