高中數學關鍵解題圖表：主題 01｜循環小數與數線分點公式（公式 1、2）
16:9 精準座標資訊圖表
📌 原題條件：數線上有 $A(0.\overline{27})$、$B(1.2\overline{6})$ 兩點，$P$ 在 $\overline{AB}$ 上且滿足 $\overline{PA} : \overline{PB} = 2 : 3$
🎯 求解目標：將循環小數化為最簡分數，並求內分點 $P$ 坐標 $(1)$
1. 題目條件與模型
  • 結合公式 1 與公式 2 分點
  • 端點 $A = 0.\overline{27}$ 為純循環
  • 端點 $B = 1.2\overline{6}$ 為混循環
  • 距離比例 $m : n = 2 : 3$
2. 關鍵階段一：小數化分數
  • 純循環：$\displaystyle 0.\overline{abc} = \frac{abc}{999}$
  • 點 $A$ 化簡：$\displaystyle a = \frac{27}{99}$
  • 約分得：$\displaystyle a = \frac{3}{11}$
  • 點 $B$ 化簡：$\displaystyle b = \frac{19}{15}$
3. 關鍵階段二：交叉求分點
  • 內分點：$\displaystyle P = \frac{mb+na}{m+n}$
  • 代比例：$\displaystyle P = \frac{2b+3a}{5}$
  • 代數值：$\displaystyle P = \frac{38}{75} + \frac{9}{55}$
  • 通分得：$\displaystyle P = \frac{553}{825}$
4. 關鍵數據對照
  • 左端點：$\displaystyle A = \frac{3}{11}$
  • 右端點：$\displaystyle B = \frac{19}{15}$
  • 通分和：$\displaystyle \frac{135+418}{825}$
  • 最終解：$\displaystyle (1) = \frac{553}{825}$
5. 核心公式與轉化
  • 循環幾位分母寫幾個 $9$
  • 不循環位數於分母補 $0$
  • 中點公式：$\displaystyle P = \frac{a+b}{2}$
  • 外分點先轉內分點再算
6. 易錯陷阱與心法
❌ 直覺陷阱：分子勿寫 $ma+nb$，須交叉相乘
⚠️ 忽略機制：混循環分子須用全部減不循環
💡 幾何直觀：離哪個端點越近，該點權重越大
高中數學關鍵解題圖表：主題 02｜雙重根號化簡與算幾不等式（公式 3、4）
16:9 精準座標資訊圖表
📌 原題條件：設 $x = \sqrt{8 - \sqrt{60}}$，且正實數 $t > 0$ 滿足函數 $f(t) = t + \frac{x^2}{t}$
🎯 求解目標：先化簡雙重根號 $x$，再由算幾不等式求 $f(t)$ 最小值 $(2)$
1. 題目條件與模型
  • 結合公式 3 與公式 4 算幾
  • 內層根號前必須湊出係數 $2$
  • 找兩正數滿足和與積關係
  • 因 $t > 0$ 符合算幾正數前提
2. 關鍵階段一：雙重根號化簡
  • 內層提 $2$：$\sqrt{60} = 2\sqrt{15}$
  • 原式化為：$\sqrt{8 - 2\sqrt{15}}$
  • 湊和積：$a=5, b=3$
  • 大減小：$x = \sqrt{5} - \sqrt{3}$
3. 關鍵階段二：算幾求極值
  • 公式：$\displaystyle \frac{A+B}{2} \ge \sqrt{AB}$
  • 代入：$\displaystyle t + \frac{x^2}{t} \ge 2x$
  • 極值：$f(t) \ge 2x$
  • 得最小值：$2\sqrt{5} - 2\sqrt{3}$
4. 關鍵數據對照
  • 化簡值：$x = \sqrt{5}-\sqrt{3}$
  • 平方值：$x^2 = 8 - 2\sqrt{15}$
  • 等號點：$t = \sqrt{5}-\sqrt{3}$
  • 最終解：$(2) = 2\sqrt{5}-2\sqrt{3}$
